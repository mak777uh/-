# Синтез: второй субстрат W2 — что литература говорит заранее

Заготовка к `docs/substrate-map.md` («дешёвый способ проверить переносимость») и §7.3
рукописи v2. Здесь нет новых источников: только то, что уже проверено в библиотеке, и
следствия для дизайна W2 — чтобы не изобретать мир, в котором вывод нечем проверить.

## 1. Что задаёт W2

По карте субстратов: строка фиксированной длины, репликация с мутациями, общий пул
ресурса, «смерть» при нехватке ресурса, скрытое качество участков (видно только после
пробы). Проверяемое утверждение одно: **«обучение/пластичность полезна только при неполной
информации»**.

## 2. Что уже известно про строковых репликаторов

- **Tierra (A1):** без пространства получается экология (паразиты → иммунитет →
  гиперпаразиты → читеры), но не новые функции; разнообразие мерилось размером, а не
  функцией. Вывод для W2: **паразитизм — режим по умолчанию**, его надо либо ограничить
  (узнавание/пространство), либо измерять отдельно.
- **Avida (A2):** функция появляется только там, где промежуточные шаги вознаграждаются;
  в среде «только цель» — 0/50. Вывод для W2: если у репликатора одна цель (выжить),
  новшеств не ждать — нужны ступени или смена задачи.
- **Порог ошибок (P2, P3):** критическая μ зависит от длины «текста» и **экспоненциально от
  размера популяции**; при N ≥ 250 кривая выполаживается. Вывод для W2: длину строки и
  популяцию фиксировать **до** свипа μ, иначе порог будет плавать.
- **IFD (P1) и matching/melioration (P11–P13):** выбор по подушевой отдаче; локальное
  правило сходится к пропорции, а не к максимуму. Вывод для W2: «пластичная стратегия» —
  это melioration, и её проигрыш при полной информации ожидаем по теории, а не по нашей
  реализации.
- **Нестационарные бандиты (P14):** если качество участков меняется, нужен discount/окно,
  иначе вес не двигается. Вывод для W2: скрытое качество должно **меняться** (или быть
  статичным, но неизвестным) — это разные тесты; зафиксировать заранее, какой из них W2.

## 3. Что это значит для дизайна W2 (до прогонов)

| Решение | Как делать | Почему |
| --- | --- | --- |
| Длина строки и популяция | фиксировать до свипа μ | иначе μc(N) смешивается с длиной (P2/P3) |
| Неопределённость | скрытое качество участка, раскрывается **пробой** | это и есть «неполная информация»; иначе bandit без сигнала |
| Полная информация (контроль) | то же, но качество видно сразу | без этого контроль не отличается от опыта |
| Пластичная стратегия | правило, обновляющее выбор по исходу пробы | это melioration; ожидание — matching, не максимум (P11–P14) |
| Паразитизм | либо пространство/узнавание, либо измерять чистую долю | Tierra: без ограничения паразиты съедают сигнал (A1) |
| Цель | не одна: ступени или смена задачи | Avida: «только цель» — 0/50 (A2) |

## 4. Предсказания и критерии (заранее)

1. **Полная информация:** фиксированная стратегия ≥ пластичной на 3 сидах; разница
   различима (CI не пересекает 0), иначе W2 не тест.
2. **Скрытое качество:** пластичная стратегия обгоняет фикс; величина зависит от цены
   пробы — это и есть «обучение покупает информацию».
3. **Смена качества во времени:** без discount/окна пластичная не отслеживает (P14);
   с окном — отслеживает. Это отдельное плечо, не смешивать с п. 2.
4. **Паразитизм:** доля «читеров» растёт без пространства и падает с пространством/узнаванием
   (A1); если не так — модель W2 отличается от Tierra, и это надо записать.

## 5. Чего W2 не проверит

- Ничего про морфологию и тело: маски нет, «форма» — только строка.
- Ничего про цену за клетку: цена здесь за пробу/поддержание репликатора.
- Ничего про групповую выгоду, если группы не определены конструктивно: клональные
  группы в W2 — отдельное решение, а не следствие.
- Перенос «смерти в бедной зоне» требует, чтобы цена превышала доход бедной зоны; иначе
  среда безразлична (тот же урок, что в W1).

## 6. Что делать после W2

- Если п. 1–2 подтверждаются: утверждение перестаёт быть про W1 и становится кандидатом в
  общее (с оговоркой «для двух субстратов»).
- Если нет: граница — «только телесные миры с ценой за клетку», и это честнее обобщения с
  одного субстрата.
