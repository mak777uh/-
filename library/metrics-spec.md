# Спецификация метрик: разнообразие, новизна, отбор

Зачем: сейчас у нас есть только `pop_time`, доли типов и полураспад. По ним нельзя отличить
эволюцию от дрейфа меток. Ниже минимум, который надо логировать и считать.

## 1. Поля в артефакте серии (логировать всегда)

| Поле | Тип | Что означает |
|---|---|---|
| `step` | int | шаг |
| `alive_cells` | int | живых клеток |
| `types_alive` | int | сколько **различных** типов присутствует |
| `type_counts` | dict | тип → число клеток (для долей и разнообразия) |
| `births_by_type` | dict | тип → число делений за шаг |
| `deaths_by_type` | dict | тип → число смертей за шаг |
| `env_excess` | float | избыток ресурса над абиотическим контролем |
| `generation_length` | float | медианное время от деления до деления линии |
| `mutation_events` | int | сколько раз потомок получил тип, отличный от родителя |

## 2. Метрики (формулы)

1. **Разнообразие (Shannon)**: `H(t) = -Σ p_i log p_i`, `p_i = type_counts[i] / alive_cells`.
   Отчёт: медиана `H` за окно и её тренд (первая половина vs вторая).
2. **Поток новизны**: `novelty(t0,t1) = |{типы, впервые появившиеся в окне и прожившие ≥ N шагов}|`.
   N по умолчанию 50 (≈ 1/4 поколения), параметр в отчёте.
3. **Дифференциальное воспроизводство**: `ρ = Spearman(признак типа, births_by_type / type_counts)`
   по всем типам за окно. Если `ρ ≈ 0` — отбора по признаку нет, любые слова об отборе снимаются.
4. **Наследие в единицах поколения**: `half_life / generation_length`. Сейчас 20–41 / 125–206 ≈ 0.1–0.3.
5. **Кривая выживания линий**: доля линий, доживших до T, как функция размера инокулята.

## 3. Критерии (что считаем «условие выполнено»)

| Условие | Критерий |
|---|---|
| A информация | выигрыш learning-плеча ≥ порога (4.7 %) при частичной информации; при полной — ≤ порога |
| B изменчивость | `mutation_events > 0` и `novelty > 0` при `m > 0`; при `m = 0` новизна нулевая |
| C наследование среды | `half_life / generation_length ≥ 1` |
| D линия | доля выживших растёт с инокулятом (монотонно на 1/2/5/10) |
| E отбор | `ρ ≥ 0.3` и устойчиво по сидам |

## 4. Что это даёт

- каждое утверждение об «эволюции/развитии» опирается на число, а не на слово;
- отрицательный результат становится сильным: «при `m=0` новизна = 0 при любых условиях» —
  это не «не получилось», а измеренная граница;
- метрики совместимы с OEE-языком (E1 Taylor 2019) и не требуют новых зависимостей.
