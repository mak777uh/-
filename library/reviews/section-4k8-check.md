# Проверка §4k.8 (04.11.2026): числа сходятся, у мощности не назван тест

Проверял: `manuscript/paper.md` §4k.8 (коммит `82a462f3`). Бюджет — 20 минут, артефакт — эта записка.

## 1. Cochran–Armitage: воспроизводится точно

`4/15, 7/15, 10/15` при очках 0/1/2: `p̂ = 0.4667`, **z = 2.196** (в тексте 2.20), **односторонний p = 0.0141**
(в тексте 0.014). ✅ Пересчёт независимым кодом, расхождений нет.

## 2. Мощность «15 из 100»: воспроизводится, но только для двустороннего теста

Текст: «десять сидов поймали бы тридцатипунктовый эффект пятнадцать раз из ста». Мой пересчёт (точный
Fisher, `n = 10` на плечо, 20 000 повторов):

| база → эффект | односторонний | **двусторонний** |
|---|---|---|
| 0.05 → 0.35 | 0.32 | **0.153** |
| 0.10 → 0.40 | 0.30 | **0.149** |
| 0.20 → 0.50 | 0.27 | **0.132** |

**0.15 воспроизводится только для двустороннего точного теста.** ✅ Число верное.

**Но:** сам опыт X170 проверялся **односторонним** Cochran–Armitage (`p = 0.014`, направление
пре-регистрировано). Значит честная мощность того дизайна — **≈ 0.30, вдвое выше** названной.

**Что это меняет.** Аргумент «десяти сидов не хватило» от этого только **сильнее** (при 0.30 всё равно
три шанса из десяти промахнуться), но цифра обязана называть тест: иначе читатель считает мощность того
теста, который в статье применён, и получает вдвое большую величину.

**Правка (текст, не числа):** «…пятнадцать раз из ста **при двустороннем точном тесте; односторонний, который
применён в X170, даёт около тридцати**».
