# IGR в наших мирах: как считать (методическая записка, 30.10)

Основание: B-092 — Schreiber 2025 (J. Math. Biol. 91, `10.1007/s00285-025-02283-0`) даёт
**invasion growth rate** для flow-kick систем и доказывает: IGR > 0 у редкого для каждой инвариантной
меры на множестве вымирания ⇒ **permanence**. Наш мир — flow-kick; значит слово «сосуществование» можно
заработать, а не заявлять.

## 1. Соответствие

| flow-kick (Schreiber) | у нас |
|---|---|
| поток (непрерывный рост/взаимодействие) | шаг мира: энергия, ресурс, смерть |
| kick (мгновенное событие) | почкование; инъекция инвайдера; внешний вход (`--inflow-live`) |
| состояние | `summary.type_counts` / `lineage_*` на шаге |
| редкий вид | линия с долей `< 5 %` живых клеток (порог объявить до счёта) |
| IGR | средний per-capita рост этой линии на окне, **пока она редкая** |

## 2. Что считать (по существующим артефактам)

Для каждого прогона и каждой линии `t`:

```
g_t(w) = (1/W) · Σ_{i=1..W} ln( n_t(s_i + Δ) / n_t(s_i) )
```

где `n_t` — число клеток линии `t` (`type_counts["T<t>"]`), окно `W` шагов, `Δ` — шаг среза, при
условии `n_t < 0.05 · alive` на всём окне. Затем IGR линии = медиана `g_t` по окнам; IGR мира = медиана
по редким линиям.

**Данные, которых не хватает:** артефакты хранят `summary` на конец прогона, но не ряд по шагам (кроме
дампов поля и `log`). Значит IGR **сейчас не считается** на прудовых сериях — нужен хотя бы один прогон с
`dump_fields`/посрезовым логом.

## 3. Ловушки (назвать в тексте)

1. **Конечный горизонт.** IGR — предел; у нас окно. Поэтому «IGR на окне», а не грань Ляпунова.
2. **Переходный процесс.** Мы уже видели пик против плато (§10bn): IGR, посчитанный на 600 шагах,
   может быть положительным, а на 1800 — нулевым. Окно фиксировать до счёта.
3. **Нули и вымирание.** `ln(0)` не определён: линии, исчезнувшие в окне, исключать **с пометкой**, а не
   выбрасывать молча (иначе IGR завышен — выжившие отбираются).
4. **Инвариантные меры.** Теорема требует их; у нас одна траектория. Значит IGR — **статистика по сидам**,
   а не гарантия permanence.

## 4. Критерий (до данных)

- если IGR редкой линии > 0 в **≥ 18 из 20** сидов при фиксированном окне — говорить «сосуществование
  в смысле invasion growth rate положительно»;
- если IGR ≤ 0 хотя бы в одном плече — «это плечо не поддерживает сосуществование»;
- **не заявлять permanence**: для него нужны инвариантные меры и бесконечный горизонт.

## 5. Что нужно от стенда (ЗАПРОС)

Один прогон пруда с пошаговой записью `type_counts` (или срезами каждые 10 шагов) — тогда IGR считается
без новых экспериментов, только по логу.
