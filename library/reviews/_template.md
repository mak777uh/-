# Обзор поля: <тема> (<дата>)

## Зачем (триггер)
Один из пяти: смена рамки/вопроса · блокирующее решение · три точечных поиска упёрлись в одно ·
выход наружу (статья/доклад, prior art) · вход в новую подобласть.
Что именно решается этим обзором: …

## Карта поля (5–8 кластеров)
| Кластер | Что установлено | Метрики/контроли | Границы | Наши источники |
|---|---|---|---|---|
|  |  |  |  |  |

## Что это меняет у нас (3–5 пунктов, каждый — действие)
1. переименовать / 2. добавить контроль / 3. сменить метрику / 4. отказаться от утверждения /
5. изменить дизайн теста.
Каждый пункт: куда именно записано (файл/строка).

## Дыры, которых нет в литературе
Что мы можем проверить, чего там нет (это и есть наш вклад).

## Чего в обзоре нет
Какие вопросы остались вне охвата и почему.

## Стоимость
Циклов потрачено: N. Если изменения не легли в файлы в тот же день — обзор считается неудачным.
