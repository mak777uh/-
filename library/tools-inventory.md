# Инвентарь софта из публикаций: что проверяет наши метрики (task-15, 25.10)

Фильтр ведущего: берём инструмент, только если он **проверяет уже заявленную метрику** или закрывает
**уже названный** гэп. Никаких «на всякий случай».

## Что мы считаем руками (по коду)

| метрика | где считаем сами | строка |
|---|---|---|
| интервалы Уилсона | `scripts/v8_matrix.py`, `scripts/founding_matrix.py`, `scripts/invader_dose_matrix.py`, `library/tools/v8_matrix.py` | `def wilson(...)` в четырёх файлах |
| β1 (персистентная гомология, грубо) | `scripts/map_metrics.py` | `def betti1(grid)` — сетка 32×32, 4-/8-связность |
| взаимная информация | `scripts/individuality.py` | `def mutual_information(x, y, bins=8)` — гистограммная оценка |
| суррогаты | `library/review-live-signals.md`, `library/tools/…` (онлайн-вариант) | скользящее окно → FFT → фазы → IFFT |
| чувствительность (Sobol/Morris) | — | не считаем |
| инварианты CA | `scripts/map_metrics.py`, `morphogenesis/…` | вручную |

## Топ-3 (что просить ставить)

1. **statsmodels** — закрывает самый частый гэп: Уилсон считается руками **в четырёх файлах**, а от
   него зависят все «доля выживших» в V8/D/B. Риск: нет. Проверка: сверка `wilson(k,n)` на 20 парах.
2. **pyinform** — наша MI в `individuality.py` — гистограммная, с фиксированным `bins=8`; это
   смещённая оценка. PyInform даёт корректные оценки и станет референсом для H-AB/LIT-009. Риск: нет.
3. **gudhi** — единственный удобный способ проверить `betti1()` на **кубическом комплексе** именно для
   наших 32×32 карт; ripser MIT, но для бинарных карт требует своей фильтрации. Риск: **GPL-3** —
   принимать только как dev/CI-инструмент, не в рантайм.

## Что не берём

- **giotto-tda** — AGPLv3 заражает проект; нам нужен один расчёт β, а не пайплайн.
- **JIDT/jpype** — JVM и jar вне pip; LIT-005 отложено.
- **SALES/lifelines/cellpylib** — нет текущего гэпа (появятся при свипах и survival-анализе).
