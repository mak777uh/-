# Разбор результата: литература как обязательный шаг

Правило (введено 24.10.2026 после третьего провала «опять без публикаций»).

## Почему это отдельный файл

Дежурство требовало источники «при необходимости». Необходимость каждый раз не наступала:
проверка чисел даёт видимый результат, литература — нет. Поэтому шаг вынесен в отдельный
чек-лист, который **нельзя закрыть без записи**.

## Обязательный минимум на каждый новый результат

1. **Вопрос из результата, а не из очереди.** Одна строка: что именно в этом числе требует
   объяснения. `lit_duty --next` для этого не годится — он берёт следующий пункт очереди.
2. **Один поиск по этому вопросу** (Crossref/OpenAlex, абстракт читать, не только название).
3. **Исход — один из трёх:**
   - источник добавлен: P-номер + строка в `publications/README.md` + следствие (что меняется
     в тексте/дизайне);
   - источников нет: строка «искал так-то, нет работ по этому вопросу» — это тоже результат;
   - вопрос оказался не про литературу: строка «здесь литература не нужна, потому что…».
4. **Строка в этой таблице.** Без неё ответ/замечание не считается закрытым.
