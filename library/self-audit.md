## 5. Куда переносить усилия (предложения)

### 5.1 Роль — три функции, а не одна

| Функция | Что делаю | Почему это импакт |
|---|---|---|
| **Независимый проверяющий** | семантика метрики, контроль, интервал, граница; встречный тест | 7 из 7 найденных ошибок — здесь |
| **Аналитик литературы под утверждение** | на каждый пункт очереди и каждое условие A–E — один поиск, который меняет формулировку/контроль/метрику/тест | именно так вошли NC3, placebo, matching habitat choice, founder effect, NFDS-поправка, интервалы, три процесса эволюции |
| **Куратор условий A–E** | по каждому условию: якорь, метрика, тест опровержения | это цель проекта, а не статья |
| **Владелец метрик новизны** | спецификация и расчёт разнообразия/новизны/дифференциального воспроизводства | без метрик «эволюция» неотличима от дрейфа |

### 5.2 Метрики, которые надо ввести (спецификация)

Для каждой серии логировать:

1. `types_alive_series[t]` — число живых типов на шаге t (не доля, а число).
2. `type_lifetime[t]` — сколько шагов живёт каждый тип; **поток новизны** = число типов с
   временем жизни ≥ N (N = 50 шагов) за окно.
3. `offspring_by_type` — число потомков на тип; **дифференциальное воспроизводство** =
   корреляция (Спирмен) признака с числом потомков.
4. `env_excess_half_life / generation_length` — наследие в единицах поколения (нормировка).
5. `lineage_survival_curve` — доля линий, доживших до T, по размеру инокулята.

Без 1–3 любое утверждение об «эволюции» остаётся словом.

### 5.3 Ритм

- **3 проверки в день** (утро/день/вечер) + событийный сторож; 20-минутный крон — только в дни
  активных серий.
- На освободившееся время — **одна глубокая задача в день**: метрики, досье условия, встречный тест.
- Одна запись на факт: `notices` — для учёного, `answers` — только для несущих выводов,
  `synthesis` — только для текста статьи. В чат — ≤6 строк, без пересказа.

### 5.4 Чек-лист перед публикацией вывода (жёсткий)

1. Семантика метрики прочитана в коде, а не угадана.
2. Артефакт в репозитории, не в `_hourly` (R12).
3. Контроль/placebo есть.
4. n и интервал указаны; для доли — Wilson/Clopper–Pearson.
5. Граница сформулирована до числа.
6. Встречный тест назван.
7. Литературный якорь — 1 источник или «нет работ».
