- **Тип:** `prior_art`; **статус:** `accepted`; **волна:** `current`

### B-014. Серия freq_* (два типа A/B, ресурс с частотной зависимостью) ставит вопрос, изве

- **Тип:** `known_fact`; **статус:** `accepted`; **волна:** `current`
- **Цель:** `experiment` `freq_series`, _hourly/polish/freq_*.json; docs/world-design §10s
- **Утверждение:** Серия freq_* (два типа A/B, ресурс с частотной зависимостью) ставит вопрос, известный в экологии: сосуществование типов. - **Доказательство:** [`library/hypotheses/pond-lineage.md#P15`](../library/hypotheses/pond-lineage.md#P15), [`library/hypotheses/pond-lineage.md#P16`](../library/hypotheses/pond-lineage.md#P16)

- **След:** insights: I-032; tasks: task-9
- **Решение:** критерий сосуществования должен быть инвазионным (Chesson 2000), иначе мы переоткрываем частотную зависимость; проверяемо на существующей серии freq_*

### B-015. Серия freq_* (45 прогонов, 5 сидов/группу) даёт первый режим, где обучение обгон

- **Тип:** `known_fact`; **статус:** `new`; **волна:** `current`
- **Цель:** `experiment` `freq_series`, _hourly/polish/freq_*.json

## Правила (коротко)

1. Одно замечание — одна строка: тип, цель, утверждение, доказательство, действие.
2. Без ссылки на запись `library/` замечание не заводится.
3. Статус ставит не библиотекарь; `declined`/`deferred` — только с причиной.
4. Потолок шума: ≤ 3 новых замечания за проверку библиотекаря.
5. Отклонённое и отложенное остаётся: это след, а не мусор.
