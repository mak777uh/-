# Индекс: источник → гипотеза → эксперимент

Единственный курированный вход в библиотеку. Здесь одна строка на источник, и у
каждой строки видны четыре вещи: **что мы из него берём**, **какую гипотезу он
порождает**, **каким экспериментом она проверяется** и **чем это кончилось**.

Файл нужен для трёх задач:

1. **Цитирование в статьях.** В [`articles/`](../../articles/README.md) ссылка берётся
   отсюда, а не из памяти и не из чужой статьи.
2. **Регулярное обновление.** Новая работа → строка; гипотеза проверена → меняется
   статус, а не удаляется строка.
3. **Проверка контура.** Если в статье цитируется источник, которого нет в этом
   индексе, — это дырка, а не стиль.

> **Правовая рамка.** Никаких полных текстов, PDF и переводов. Метаданные, ссылки
> (DOI/arXiv/издатель), наши заметки и короткие атрибутированные цитаты. Подробные
> разборы — в [`../levin/`](../levin/README.md),
> [`../hypotheses/README.md`](../hypotheses/README.md) и
> [`../hypotheses/nca-lineage.md`](../hypotheses/nca-lineage.md).

- **Дата сверки метаданных ядра:** 2026-10-22 (восемь источников родословной и двадцать
  источников прохода 2024–2026 — сверены 2026-10-21; десять источников прохода 2026-10-22 —
  по Crossref/arXiv, см. раздел F и [`../hypotheses/reproducibility.md`](../hypotheses/reproducibility.md)).
- **Сроков здесь нет.** Работа идёт по готовности гейтов, а не по календарю; даты
  стоят только там, где зафиксирован факт (когда сверяли, когда закрыли прогон).

## Словарь статусов

| Статус | Значит |
| --- | --- |
| `supported` | гипотеза проверена, данные за неё; ссылка на отчёт обязательна |
| `refuted` | гипотеза проверена, данные против; остаётся в индексе и в `negative_results.md` |
| `exploratory` | результат есть, но вне предзарегистрированного протокола; не свидетельство |
| `not_run` | входит в план, не запускалась |
| `planned` | правила и скрипт готовы, прогона нет |
| `blocked` | требует решения владельца (новая тренировочная серия, H4, WP5) |

## Что этот индекс не означает

- **Это не литературный обзор.** Полнота не цель; цель — связка «источник →
  проверяемая гипотеза → прогон».
- **`not_run` не значит «неверно».** Гипотеза без прогона — заявка, а не результат;
  в статьях она идёт как следующая гипотеза, а не как вывод.
- **`exploratory` не значит `supported`.** Вне предзарегистрированного протокола
  артефакт описывает наблюдение; в тексте это формулируется как наблюдение.
- **Ничего о жизни, сознании или интеллекте.** Ни один источник здесь не делает
  устойчивый класс NCA живым, и мы такого не утверждаем.

## Как обновлять

1. **Новая работа** → строка в тематический раздел A–E (или новый раздел с подписью).
   Обязательны: ссылка/DOI, «что даёт», id гипотезы, эксперимент, статус, где разбор.
2. **Нет гипотезы — нет строки.** Источник, из которого не следует проверяемого
   вопроса, живёт в `hypotheses/README.md` как контекст, но не в этом индексе.
3. **Гипотеза проверена** → статус меняется на `supported`/`refuted`, добавляется
   ссылка на отчёт и артефакт. Строка не удаляется: отрицательный результат — тоже
   результат ([AGENTS.md §3a](../../AGENTS.md)).
4. **Ошибка в метаданных** → правка с пометкой «уточнено ДД.ММ.ГГГГ», а не молча
   ([`../README.md`](../README.md), правило 4).
5. **Новый id гипотезы** появляется сначала в `lab/registry.json` →
   `program.next_hypotheses`, потом здесь; иначе `python scripts/lab.py validate`
   разойдётся с текстом.
