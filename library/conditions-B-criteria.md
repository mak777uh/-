# Условие B (изменчивость): критерии, метрики, невалидные числа

Заготовлено к старту серии B (решение владельца 24.10, 16:05). Всё ниже — **пре-регистрация**:
менять после запуска нельзя, только новой серией.

## Что считаем «срабатыванием»

| Метрика | Формула | Порог срабатывания | Порог «не сработало» |
|---|---|---|---|
| Разнообразие | Shannon `H(t) = −Σ p_i ln p_i` по `type_counts` | при `m > 0`: медиана `H` > **0.1** и рост от первой к последней четверти | при `m > 0`: `H` ≤ 0.1 или падает |
| Поток новизны | число типов, впервые появившихся и проживших ≥ **50** шагов | при `m > 0`: ≥ **1** новый устойчивый тип на прогон | при `m > 0`: 0 в большинстве прогонов |
| Контроль нуля | то же при `m = 0` | **новизна строго 0** (иначе метрика новизны ловит артефакт) | если при `m=0` новизна > 0 — вся метрика невалидна |
| Дифференциальное воспроизводство | Спирмен(`type_traits`, `births_by_type`) | `ρ ≥ 0.3` при `m > 0` и `ρ ≈ 0` при `m = 0` | `ρ` не считается (нет признака типов) |

Дозовая сетка: `m ∈ {0, 0.001, 0.01, 0.05}` × 3 сида. **Срабатывание условия B** — монотонный рост
новизны по дозам при нулевой новизне на `m = 0`.

## Что делает число невалидным

1. Нет `type_counts_series` → метрики разнообразия и новизны не считаются (не «ноль», а «нет данных»).
2. Нет `births_by_type` и `type_traits` → дифференциальное воспроизводство не считается; **нельзя**
   писать «отбора нет».
3. При `m = 0` новизна > 0 → ошибка логгера (тип терялся или переименовывался), серия перезапускается.
4. Меньше 20 делений в прогоне → `generation_length` = `null` (не оценка).
5. n < 3 сидов или коллапс более 1 из 3 → метрика сообщается по каждому сиду отдельно, медиана без
   интервала не пишется.
6. Разные `freq_dep`/`layout`/`type_mode` внутри одной сетки → прогоны нельзя объединять.

## Статистика (записано заранее)

- Доли (выжившие, фиксации) — только с интервалом Wilson; при n = 3 интервал не приводится,
  вместо него диапазон по сидам.
- Сравнение доз — **тренд** по рангам (Cochran–Armitage для долей; для `H` — сравнение медиан
  с диапазонами), а не попарные тесты.
- Различие заявляется только при **неперекрывающихся** интервалах или монотонном тренде.

## Инструмент

`python library/tools/trait_metrics.py --src morphogenesis/experiments/E09_pond --glob "mut_*.json" --json _out.json`

Считает `shannon_median/first/last`, `novelty_flux` (окно 50 шагов), Спирмена; при отсутствии поля
пишет `invalid: <причина>`, а не ноль. Проверено на текущих артефактах: 24 файла `colinv3_*` —
все `invalid: нет type_counts_series` (поля ещё не логируются) — это ожидаемо и правильно.

## Что должен записать учёный в summary серии B

```json
{"mutation_rate": 0.01,
 "type_counts_series": [{"0": {"A": 120}}, {"1": {"A": 118, "A1": 2}}],
 "births_by_type": {"A": 210, "A1": 4},
 "type_traits": {"A": 0.0, "A1": 0.01},
 "generation_length": 143.0, "generation_divisions": 87}
```
Без `type_traits` третий критерий (отбор) не считается — это не «нет отбора», а «нет данных».
