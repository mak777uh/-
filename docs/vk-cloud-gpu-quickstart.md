# Быстрый старт: GPU в VK Cloud для проверки TF32 (H-REPRO-9)

Инструкция для того, кто ни разу не пользовался VK Cloud. Цель — за 15 минут
получить работающую машину с GPU, прогнать скрипт и прислать мне один JSON-блок.

Бонусов у нас 3 000 ₽; L4 стоит ≈99 ₽/ч, один прогон скрипта ≈40 минут, то есть
два прогона ≈150 ₽. Останавливать машину обязательно — пока она в статусе
«Запущена», бонусы расходуются.

## 1. Что подготовить (5 минут)

1. Аккаунт VK ID (тот, на который пришли бонусы) — зайти на <https://cloud.vk.com>.
2. Убедиться, что бонусы видны: раздел «Баланс» / «Биллинг» — должно быть
   ~3 000 ₽.
3. Создать проект, если его нет: «Проекты» → «Создать проект» → имя любое
   (например `morphogenesis`), регион — ближайший (Москва).

## 2. Создать виртуальную машину с GPU

В проекте: «Облачные вычисления» → «Виртуальные машины» → «Создать».

| Поле | Что выбрать |
|---|---|
| Операционная система | Ubuntu 22.04 LTS (если есть образ с NVIDIA/CUDA — брать его) |
| Конфигурация | с GPU: **L4** (в крайнем случае **A100** — у него TF32 тоже есть) |
| Диск | 30 ГБ (хватит: чекпоинт 0.5 ГБ) |
| Сеть | «Назначить публичный IP» — включить |
| Доступ | **пароль root/пользователя** (проще всего) ИЛИ SSH-ключ |

Важно: для работы скрипта нужен драйвер NVIDIA не ниже 550 (под torch cu124).
Если берёшь образ с предустановленным CUDA — драйвер уже есть. Если обычный
Ubuntu, после входа поставь драйвер (раздел 5).

После создания дождись статуса «Запущена» и запомни публичный IP.

## 3. Зайти на машину

**Самый простой путь — веб-консоль:** в списке ВМ нажать «Консоль» (или
«Подключиться»), ввести логин/пароль из шага 2. Дальше все команды — прямо в
браузере, SSH не нужен.

**Если предпочитаешь SSH** (Windows PowerShell):

```powershell
ssh ubuntu@<ПУБЛИЧНЫЙ_IP>
# или, если пользователь root:
ssh root@<ПУБЛИЧНЫЙ_IP>
```

## 4. Прогнать проверку

Сначала убедись, что GPU виден:

```bash
nvidia-smi
```

Дальше — три команды:

```bash
sudo apt-get update -qq && sudo apt-get install -y -qq git python3-pip
curl -fsSL https://raw.githubusercontent.com/mak777uh/-/main/scripts/cloud_gpu_repro.sh -o repro.sh
bash repro.sh tf32
```

Первый прогон: клонирует репозиторий, поставит torch, обучит сид 42 (≈30 минут),
посчитает перепись (≈7–10 минут) и напечатает блок:

```
FROM_CLOUD_JSON
{"kind": "cloud_gpu_repro", "mode": "tf32", ...}
TO_CLOUD_JSON
```

Второй прогон (та же карта, выключенная точность):

```bash
bash repro.sh fp32
```

## 5. Если драйвера нет

`nvidia-smi: command not found` означает, что образ без драйвера. Для Ubuntu
22.04:

```bash
sudo apt-get update -qq
sudo apt-get install -y -qq nvidia-driver-550
sudo reboot
```

После перезагрузки подождать минуту, снова зайти и проверить `nvidia-smi`.

## 6. Что прислать

Скопируй в чат **оба** блока `FROM_CLOUD_JSON … TO_CLOUD_JSON` (для `tf32` и для
`fp32`). Этого достаточно: там GPU, архитектура (`capability`), версии torch и
CUDA, sha256 весов и классы переписи.

## 7. Не забыть остановить

«Виртуальные машины» → выбрать машину → «Остановить» (или «Удалить», если больше
не нужна). Пока машина запущена, бонусы тратятся.

## Что это докажет

- **L4 (Ada, TF32 есть):** при `tf32` должен быть `struct_2` ≥ 52/64, при `fp32`
  — нет. Это повтор нашего локального результата на чужом железе.
- **V100 в Cloud.ru (Volta, TF32 физически нет):** `struct_2` не должен
  появиться ни при какой настройке. Если появится — механизм TF32 опровергнут,
  и мы честно перепишем объяснение.
