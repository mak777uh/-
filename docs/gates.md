# Гейты: откуда каждый и сколько стоил

Зачем этот файл (EBT, 27.10). Гейт без истории — это ритуал: его боятся снять и
не помнят, зачем он. Здесь у каждого гейта записано, **какой провал** его вызвал и
**сколько этот провал стоил**. Правило: новый гейт добавляется только вместе со
строкой здесь; гейт, у которого нет аварии за спиной, не добавляется (правило
«одна новая проверка в неделю» — [`ci-resources.md`](ci-resources.md)).

| гейт | из какой аварии | чем платили |
|---|---|---|
| `check_series_homogeneity.py` | серия `w1niche` снята на четырёх коммитах (§10ay); затем первый проход пересъёмки смешал **параметры**, невидимые в дампе `config` (§10be) | двое суток работы и два отзыва чисел |
| `verify_sections_numbers.py` | в таблице рукописи стояло −0.700 при пересчитанном −0.219 | устаревшее число в опубликованном тексте |
| `check_empty_aggregates.py` | шаблон имени не пропускал подчёркивания: 10 артефактов молча выпали, агрегат сказал «эффекта нет» | ложный отрицательный вывод |
| `check_metric_definitions.py` | `rho_partial` считалась не тем, чем названа (гибрид вместо частного Спирмена), расхождение до 0.5 | вердикт держался на неверной величине |
| `check_reports_index.py` | две пре-регистрации не были внесены в индекс | красный CI |
| `check_scripts.py --ci` | новый скрипт не был в `docs/scripts.md` (дважды за сутки) | красный CI |
| `make_artifact_table.py --check` | таблица артефактов отставала после правок | 5 красных прогонов CI за 1.5 часа |
| `_safe_print` + «артефакт до печати» (не гейт, правило) | `OSError: Invalid argument` убивал серию четыре раза: печать в закрытый пайп (`*>>` в PowerShell — тоже пайп) | четыре мёртвых запуска по 90 с и один — после 96 с без артефакта |
| `predictions.py --check` | четыре предсказания из четырёх не сбылись, и это нигде не считалось | неизмеренная самоуверенность |
| `log_signal_scan.py` | сбои в логах находил человек, вручную открыв `.log` | повторяющийся класс «тихая смерть прогона» |

## Что этот файл защищает

1. **От разрастания.** Видно, что 10 гейтов покрывают 9 аварий — новых не нужно, пока нет новой аварии.
2. **От немоты.** Гейт, который никогда не краснел по делу, виден сразу: у него пустая история.
3. **От «заглушить».** У каждого гейта записана цена, поэтому `continue-on-error` обсуждается не как стиль, а как отказ от конкретной защиты.
