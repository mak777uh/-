# Ночной маршрут (24.10 → 25.10): автономная работа

Владелец ушёл спать, разрешил вести автономно «самым коротким и разумным путём»,
учитывая замечания библиотекаря там, где уместно. Это маршрут и правила решений.
Ничего не публикуется, критерии по ходу не меняются, тяжёлые постановки — только те,
что уже одобрены.

## Порядок работ (сверху вниз, без перестановок без причины)

1. **L2 — пластичность в течение жизни** (идёт). 16–32 адаптивных параметра, локальное
   правило без градиента, одинаковое во всех средах. Критерий: после переключения среды
   восстановление быстрее L0 **и** статистический сдвиг параметра (парно, 3 сида, порог
   4.7%). Абляция «без L1» обязательна. Оценка: ~1 час.
2. **A-gate — только гейт soft→hard**, без полного обучения. Полдня. Обязательное
   требование (из прокси-M): дифференцировать **цель пруда** (`pop_time`/выживание), а не
   рост фигуры; достаточность — в пруду (alive ≥ 64 к шагу 200). Если гейт не проходит —
   A закрывается как результат, дальше B2 через ES.
3. **B2 — niche construction**: клетка за энергию поднимает локальный потолок ресурса.
   Три метрики: среда против абиотического контроля; время жизни изменения после удаления
   организма; коэффициент обратной связи. Абляции: «без строительства» и «без обучения».
   Минимальная версия + серия 3 среды × 2 режима × 3 сида.
4. **C — карта условий** (статья + §6 рукописи): оформляется по мере закрытия 1–3.

## Правила решений (пре-регистрация, не менять на ходу)

- **L2:** если сдвиг параметра есть и восстановление быстрее L0 в ≥2 из 3 сред — это
  первый случай внутрижизненной адаптации, пишем как положительный результат. Если нет —
  «в текущем мире пластичность не окупается», и это закрывает вопрос обучения в W1.
- **A-gate:** soft при T→0 должен воспроизводить hard в пределах 4.7% по `pop_time` и
  `alive`. Не воспроизводит — A отпадает, в soft-pond не идём.
- **B2:** если строительство даёт отложенный эффект (метрики ненулевые) и обучение бьёт
  абляцию «без строительства» больше порога — это первый механизм, где действие меняет
  будущее. Если метрики нулевые — B2 отпадает.
- **Порог** всегда: 4.7% при 3 сидах, 3.6% при 5. Отчёт — медиана/IQR/доля побед.
- **Никаких выводов за пределами проверенного семейства** (B-026): каждый раз указывать,
  что именно варьировали.

## Дисциплина (не обсуждается)

- Один логический шаг — один коммит с «почему»; тесты, `lab.py validate`, `check_links`,
  сверка чисел рукописи перед коммитом.
- Агрегаты собирать только через `aggregate_check`; при расхождении с артефактом — стоп.
- Библиотека: `library_inbox.py` в начале каждого цикла; новые замечания — решение в тот
  же цикл (accepted/declined/deferred с причиной).
- Веса неканонические удалять только по §5a с записью в `lab/retention.json`.
- Публикации, депозиты, внешние действия — запрещены до утра и до «ок» владельца.
- Диск: при < 10 ГБ — чистка по §5a до тяжёлых прогонов.
- Если серия упала: фиксировать `failed`/`aborted` и причину, не маскировать.
