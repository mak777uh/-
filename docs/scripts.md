# Скрипты: что делает и кто вызывает

Документ существует по делу: `scripts/check_scripts.py --ci` считает скрипт мёртвым,
если на него нет ссылки ни в одном `.md`, тесте, workflow или другом скрипте. Таймеры
и живые сессии — не файлы, поэтому скрипты, которые вызывает ведущий по расписанию,
перечислены здесь явно.

| скрипт | что делает | кто вызывает |
|---|---|---|
| `farm_reader.py` | читает результаты CPU-фермы: pull, сводка, провенанс, статусы прогонов, отчёт `reports/farm-latest.md` | цикл здоровья (3 ч), вручную |
| `safe_commit.py` | коммит через `make verify`: красный не пускает, печатает staged-файлы | ведущий, все агенты |
| `w2bud_metric_variants.py` | пересчёт W2-bud 24 вариантами определений (S/C/R), файл `reports/2026-10-25-w2bud-metric-variants.json` | ведущий, ревью метрик |
| `make_day_poster.py` | постер дня: несколько панелей из артефактов | утренняя сводка |
| `make_simple_poster.py` | упрощённый постер для не-экспертов | утренняя сводка |
| `make_day2_picture.py` | пятипанельный постер объектов мира (day-2026-10-25) | утренняя сводка |
| `self_review.py` | самопроверка: сверяет обещания из отчётов с артефактами | цикл здоровья, вручную |

| `zenodo_upload.py` | депозит весов в Zenodo без браузера: `--plan`, `--check-token`, `--upload`, `--publish` (токен в `..\_zenodo\.token`) | ведущий, раз в месяц / после тега |

| `check_draft_numbers.py` | сверяет числа статьи с агрегатами и ловит запрещённые формулировки «доказано/всегда/исчез»; запускается вручную по черновику | ведущий перед отправкой препринта |

| `make_arxiv_figures.py` | собирает четыре фигуры препринта прямо из агрегатов в git (I против нуля, цена, выживание и время жизни, соседство) | перед сборкой статьи, ведущий |

| `run_replicator.py` | мир R1 без сетки: единица размножения — явный параметр k, порог на репликатор, учёт экспозиции по линиям | пилот и серия R1 (H-ALIVE-50) |

| `w2bud_lines_matrix.py` | агрегат серии пилотов `w2bud_lines`: пары «маневр конструкции → число линий с данными»; доказательство «конструкция не даёт ≥12 линий» | ведущий, при закрытии поиска маневра |

| `response_independent.py` | отклик признака величиной, независимой от `w` (рождения/клетко-шаги): медиана, доля положительных, совпадение знака с `rho(признак, w)` | ведущий, при сверке вывода об отклике |

| `check_series_homogeneity.py` | серия должна быть снята одним коммитом кода: иначе парное сравнение плеч недействительно (реестр — `lab/homogeneity.json`) | гейт в `lab_health` |

| `w1niche_free_matrix.py` | агрегат пересъёмки наследования в просторной зоне: парное сравнение `legacy` − `adjacency_exact` по сидам, знаковый тест, `underpowered` по фильтрованным клеткам, провенанс по коммитам | исполнитель, при закрытии H-ALIVE-52 |

| `w2bud_quota_matrix.py` | агрегат серии с квотой: вызывает `analyse()` общего агрегатора (одно определение цены) и сравнивает плечи по `rho_partial_energy`, линиям с данными и доле заблокированных делений | ведущий, H-ALIVE-53 |
| `w2bud_killwinner_matrix.py` | агрегат серий kill-the-winner: вызывает `analyse()` общего агрегатора (одно определение цены), считает среднее по Фишеру, ДИ по z, `1/Σp²`, долю смертей от механизма и проверку критерия пре-регистрации | ведущий, H-ALIVE-54/55 |

| `coexistence_metrics.py` | метрики сосуществования линий из артефактов: `1/Σp²` (эффективное число линий), Pielou `H/ln S`, rarefied richness при фиксированном бюджете, `dominant_share`; знаменатели — живые клетки и бюджет разрежения | учёный, п.1 мемо 27.10 |

| `predictions.py` | реестр предсказаний: что обещали до данных и что вышло; `--check` требует коммит пре-регистрации и исход | ведущий, EBT 27.10 |
| `log_signal_scan.py` | майнер логов прогонов: сигнатуры сбоев (OSError, Traceback, NaN, замок занят) и их повторяемость | ведущий, LDD 27.10 |

| `make_ledger.py` | журнал экспериментов в README: id и статусы собираются из `lab/registry.json` (`--sync`), `--check` ловит дубли, пропуски и расхождение статусов; описательные колонки не трогает | ведущий, решение владельца 27.10 |

## Общие правила

- Скрипт без ссылки и без вызова — мёртвый: удалять или дописывать сюда причину, почему он нужен.
- Скрипты, вызываемые таймером, обязаны быть перечислены в этой таблице: таймер — не файл, гейт его не видит.
- Каталог `lab/analysis-queue.json` и ферма описаны в `docs/optimality.md`.
