# Проверка: в мире с гейтом зажигания основание колонии не является барьером — одна клетка даёт колонию 520–665 (50/50), порога в N = 1…20 нет

- **Раздел/строка CLAIMS:** §4h `manuscript/paper.md:727-742`; `manuscript/CLAIMS.md:49` (статус `подтверждено (в модифицированном мире)`, агрегат `founding_matrix.json`)
- **Вердикт:** держится с оговоркой
- **Что пересчитано:** `morphogenesis/experiments/E09_pond/founding_matrix.json` (50 строк) и 50 сырых артефактов `found_n{1,2,5,10,20}_seed{1..10}.json`: `alive_final`, `survived`, `grew`, `invalid_reason`, `ignition_gate`, медианы по дозам, разница медиан N=1 и N=20.
- **Расхождение:** числа **воспроизводятся**. N=1: `alive_final` = 520, 553, 561, 576, 585, 586, 588, 610, 620, 665 → диапазон 520–665, медиана **585.5** (в тексте 586); медианы по дозам 585.5 / 599.5 / 601.0 / 645.0 / 687.0 (текст: 586 / 600 / 601 / 645 / 687 — округление полуцелых вверх); медианы N=20 к N=1 = **+17.3 %** (текст «~17 %»); основание 50/50, по каждой дозе 10/10, `invalid_runs = 0`, `ignition_gate = true` во всех 50 строках. `by_n` использует поле `dose` и рядом `runs` / `valid_runs` (переименование из AGENTS §3c выполнено). Оговорка: `paper.md:744-745` ссылается на `aggregate_check` этого агрегата, а поля нет (см. `2026-10-25-posthoc-confirmed.md`).
- **Проверки на устойчивость:** утверждение живёт только внутри мира с гейтом, и это в строке CLAIMS уже помечено («в модифицированном мире»), а в §4h — прямо: тот же прогон без гейта даёт 66679 / 449 / 0.951, с гейтом 91623 / 670 / 1.000, то есть гейт меняет не только зажигание, но и рост. Значит перенос «нет эффекта основателя» на серии V8/D недопустим, и рукопись это пишет. Второе ограничение по существу: проверен диапазон N = 1…20 при колонии ~510–748, то есть **2.7–3.9 % населения**; это тот же режим «редкой линии», в котором §4h и наблюдает 0/10, поэтому результат не снимает вопрос, а переносит его: линия не удерживается не из-за размера основателя.
- **Что убьёт утверждение:** прогон с гейтом, где N=1 не даёт колонии (сейчас 10/10), или гейт-мир с N ≥ 100, где основание перестаёт удаваться — тогда «порога нет» ограничивается диапазоном, а не отсутствием порога. Для статуса — ужесточение: утверждение станет неверным, если гейт-мир окажется не тем же миром, что и серия основания (сейчас `rule_sha256` в `founding_matrix.json` один на все 50 строк, но `git_dirty = true` во всех строках: прогоны сделаны из грязного дерева, и хеш правила не привязан к коммиту).
- **Что предложить ведущему:** строку оставить, но добавить в §4h одну фразу о диапазоне доли населения (до 3.9 %) — иначе «порога нет» читается шире, чем измерено; и убрать из `paper.md:744-745` ссылку на несуществующий `aggregate_check`.
