- **Расхождение:** none ("311 of 742", "258 worlds", "1.205", "20.7 … 14.3", "0.517 … 0.208", "52 % against 21 %"). The article's attribution of the drop to repeated runs is directionally right: 258 worlds from 311 rows means ~17 % of the mixed rows are repeats, and the world bootstrap puts the typical resample below the bar.
- **Проверки на устойчивость:** the drop is inside the test's own bar once worlds are the unit (14.3 < 20), and the bootstrap share 0.208 < 0.5, so the sign of the conclusion is stable; the median resampled drop (13.15) sits just below the bar, so "below the bar" is a majority, not a certainty. - **Что убьёт утверждение:** a refit with a world random effect that returns the deviance drop above 20 (the article's own test 4), or a second seed per phase that raises the number of independent worlds so that the run/world repetition falls, or a larger bootstrap in which the world share-above-20 rises above 0.5. A different deviance estimator (free two-parameter MLE instead of the fixed grid) that moves the drop materially would also matter; both drops here are ~10 % of the nominal deviance, so the estimator choice is not obviously innocuous.

## What could not be checked

- **The bridge ratios themselves cannot be recomputed from the committed repository.** The committed per-world slices store only `[step, [id, area, cx, cy]]`; the field values live in `_hourly/x19*_fields/<arm>/c###/x19*_c###_t<step>.npy`, which is untracked and exists only on this machine. I recomputed every ratio from those arrays independently and matched the aggregates on all 1008 worlds (max |Δ| = 0), but a referee with only a git checkout cannot. To make the ratio-derived statistics checkable externally, commit the contact-step field (or the contact ratio) with the compact slice: e.g. `_hourly/x192_fields/c000/x192_c000_t140.npy`, 96 × 96 float32.
- **The bootstrap intervals are reproducible only by re-running the same resampling scheme with the stored seed** (X194 seed 194, 1000 draws; X197 seed 197, 120 draws). My re-implementation matches the stored sds and shares, but this is a same-procedure reproduction, not an external interval.
- **§5.1's numbers were not recomputed** (rank association 0.982 with z = +4.64 and Fisher p = 1.7 × 10⁻⁶ from X182/X184; deviance 464.5 → 436.5, drop 28.0, from X186). They are outside groups 1–6; only X197's re-derivation of the drop on the observational pool (20.7 → 14.3) was checked, and it reproduces.
- **No simulation was re-run** (reviewer remit): the tests that would actually move the numbers are all re-runs at new seeds or a two-seed census.
