# Проверка: память по притоку — U-образная кривая, а линии истончаются, а не выключаются

- **Раздел/строка CLAIMS:** §10fk–§10fl, строки 303–307
- **Вердикт:** держится с оговоркой
- **Что пересчитано:** числа пересчитаны из агрегатов, а не из текста отчётов:
  `l1_field_x87_memory_vs_symmetry.json` (двадцать миров на приток при 0.025/0.030/0.035), `l1_field_x88_percolating_arm.json`
  (0.040/0.045/0.050) и `l1_field_x89_lineage_edge.json` (четыре полушага 0.046–0.049, восемь миров каждый). Команды:
  `python scripts/x87_analyse.py`, `python scripts/x88_analyse.py`, `python scripts/x89_analyse.py`; плюс независимая сверка
  половин: медианы по мирам 1.82 / 1.16 / 1.07 (X87) и 2.08 / 1.60 / нет (X88); внутриклеточные коэффициенты −0.050 / −0.264 /
  −0.212; частная корреляция с контролем притока −0.103; цепочка пар на мир 31.8 / 13.0 / 6.0 / 2.0 / 1.0 / 0.3.
- **Расхождение:** нет. Все числа в строках 303–307 воспроизводятся из агрегатов до последнего знака. Отдельно проверено, что
  «31.8 пары на мир» при 0.045 — это 636 пар из X88, делённые на 20 миров, а не отдельное измерение: строка 307 подписана так,
  что это видно.
- **Проверки на устойчивость:**
  - U-образность опирается на 0.040 (2.08) и 0.045 (1.60) против 0.035 (1.07). Если исключить 0.045 (там всего 636 пар и 17 из
    20 миров фиттируемых), U остаётся: 1.07 против 2.08 — разница 1.01 при SE ≈ 0.13;
  - «доля миров с одной компонентой» при 0.046–0.049 равна 1.0 во всех 32 мирах, и β₁ > 0 в 32/32 — то есть мозаика живая, а не
    мёртвая; это исключает прочтение «линии исчезают потому, что мир умирает»;
  - цепочка пар монотонна при любой из двух сводок (медиана по мирам и сумма по клетке), потому что размах внутри клеток узкий
    (8–19, 4–11, 0–2, 0–2).
- **Что убьёт утверждение:** (1) для U — серия при 0.040 на другом `k`, где полураспад вернётся к уровню 0.035; либо пересчёт
  0.040 с бо́льшим числом миров, сдвигающий медиану ниже 1.4; (2) для затухания — горизонт 12 000 шагов, на котором счётчик пар при
  0.050 не вырастет (это и проверяет X90, запущенный после этой проверки); (3) для «симметрия не несёт память» — 60 миров на клетку,
  дающие коэффициент ниже −0.3.
- **Что предложить ведущему:** держать строки как есть, но в любом тексте рядом с числом полураспада ставить число миров и
  фиттируемых (18/20, 17/20, 19/20), потому что именно эта пара чисел отличает двадцатимирную оценку от прежней пятимирной.

Проверено 02.11.2026 ведущим (мета-ревью цикла здоровья): числа взяты из агрегатов, отчёты не использовались как источник.
