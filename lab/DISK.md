# Контроль памяти и диска

Этот файл — рабочая политика, а не отчёт. Он отвечает на вопросы «что живёт на
ноутбуке», «что уезжает в GitHub» и «когда чистить». Правила согласованы с
[`AGENTS.md`](../AGENTS.md) §5/§5a и [`lab/README.md`](README.md).

## Принцип

**GitHub — тонкая память, не хранилище весов.** В git едут текст, журнал,
манифесты, JSON-агрегаты, фигуры и `census.json` (14.8 МБ). Не едут `.pt`,
TensorBoard, stdout обёртки, кадры, кеши. Полные веса (6 ГБ) в GitHub не
помещаются и не должны туда попадать; для внешнего хранения — Kaggle Dataset или
HuggingFace, для воспроизведения — lite-пакет (~20 МБ).

## Пороги

- **< 15 ГБ** — предупреждение: проверить `state.disk.free_gb`, начать уборку.
- **< 10 ГБ** — не запускать тяжёлый прогон (AGENTS.md §5a).
- **< 2 ГБ** — полная перепись запрещена (`e02b._preflight`).
- **< 2 ГБ RAM** — не запускать обучение (E02c-план).

## Что делать после каждого завершённого прогона

1. `python scripts/lab.py journal-import`
2. `python scripts/lab.py logs-archive`
3. `python scripts/lab.py state` — проверить `disk.free_gb`.
4. Зафиксировать метрики, per-run JSONL и манифест в git.
5. Удалить `nca_best.pt` при наличии `final`; удалить `nca_iter_*` после finish.
6. Записать удаление в `lab/retention.json` (путь, размер, mtime, причина),
   обновить `freed_bytes`.
7. Для нового канонического `final`: посчитать sha256, обновить
   `lab/checkpoints.json`; lite-экспорт — через `scripts/export_portable.py`
   (появится в Gate 2).
8. Коммит — только текст/JSON, без весов.

## Большой рычаг: 6 ГБ канонических весов

Сейчас локально лежат все 12 полных `nca_final.pt` (6.0 ГБ). Для переписи и
инференса они не нужны: lite-версия даёт тот же forward (проверено побитово), а
полный файл нужен только для возобновления обучения с оптимизатором/пулом.

План: после Gate 2 (lite-пакет + независимая проверка на Kaggle) выложить
полные веса во внешнее хранилище (Kaggle Dataset/HF) с sha256-манифестом и
удалить локально все, кроме положительного контроля `WP4_R-9_s2000_seed42`
(514 МБ). Это освободит ~5.5 ГБ. Удаление канонического `final` — отдельное
решение владельца (AGENTS.md §5); без внешней копии и проверки хешей не удалять.

## Исключения

- `morphogenesis/checkpoints/E02_seed0_stress1/nca_best.pt` (2.2 МБ) — v5.5,
  не загружается текущей ревизией; оставлен как исторический артефакт
  (`retention.json` → `skipped`), места почти не занимает.
- Полные логи можно удалять только после `logs-archive` и если они не нужны
  активному разбору; журнал и манифесты остаются.

## Проверка

```bash
# из корня репозитория
python scripts/lab.py state
python scripts/lab.py checkpoints
python scripts/lab.py logs-archive
```

Чистка — по событию (после прогона, перед/после внешней выгрузки), а не по
календарю: работа идёт по готовности гейтов.
