# Архив логов для GitHub

Здесь лежит **тонкий архив** завершённых per-run JSONL-логов из
`morphogenesis/logs/`. Это снимок для чтения и аудита на GitHub, а не второй
источник истины и не место для тяжёлых артефактов.

## Что попадает сюда

- только `*_log.jsonl` завершённых прогонов (`finished`, `failed`, `aborted`);
- только текстовый JSONL: start/finish, eval, метрики, ошибки;
- индекс `index.json` с `run_id`, статусом, размером и `sha256` каждого файла.

## Что не попадает

- веса `.pt` (30 ГБ, GitHub их не хранит);
- TensorBoard `events.out.tfevents.*` (бинарные и дублируют JSONL);
- stdout обёртки `lab.py run` и перенаправленные `logs_*.txt`
  (воспроизводимы командой, легко раздуваются);
- логи активных прогонов: копирование выполняется только после finish.

## Обновление

```bash
# из корня репозитория
python scripts/lab.py journal-import   # сначала закрыть манифесты
python scripts/lab.py logs-archive     # скопировать завершённые JSONL + index
python scripts/lab.py state
```

`logs-archive` не удаляет локальные логи и не трогает TensorBoard. Старые
архивные файлы, для которых исчез источник, остаются в индексе до отдельного
решения: архив append-only, как и журнал.

## Политика хранения

`final` — канонический чекпоинт для анализа. `best` — аудит-снапшот.
Промежуточные `nca_iter_*` нужны только для возобновления и удаляются после
успешного finish при наличии `nca_final.pt`; их удаление фиксируется в
[`../retention.json`](../retention.json). Полные stdout-логи и TensorBoard
остаются локальными и не коммитятся.
