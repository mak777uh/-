# H-ALIVE-45 / W2-bud: `--one-bud-per-lineage` на сидах 101–110 — пре-регистрация

- **Дата:** 2026-10-26
- **Статус:** пре-регистрация на ревью ведущего. **Шестая и последняя** переделка на утверждение «цена
  признака измерима в W2-bud»; при непрохождении срабатывает стоп-правило (ниже).
- **Зачем:** на сидах 101–110 `N = 3` дал медиану 4.0 линии при пороге 5 (`valid_n = 4/10`), а `N = 1` —
  2.5. Третий рычаг уже реализован и назван заранее: **запрет двух бутонов одной линии** не даёт предку
  забирать оба бутона компоненты.

## Дизайн

| плечо | сиды | layout | флаги | прогонов |
|---|---|---|---|---|
| `one-bud` | **101–110** | `uniform` | `--buds-per-component 3 --one-bud-per-lineage` | 10 |

Всё остальное — как в §10aw: 600 шагов, `m = 0.05`, `mutation_trait_sigma = 0.05`, `eps = 4.0`,
`freq_dep = 0`, `spore_bias = score`, `type_level = cell`, `invest_mode = fixed`, `spore_cells = 2`.

**Те же сиды, что у двух предыдущих плеч** (`N = 3` и `N = 1`, сиды 101–110), поэтому сравнение
**парное**: для каждого сида известны все три значения.

## Критерий (до данных)

1. **Направленный прогноз (парный):** линий с данными при `one-bud` **больше, чем при `N = 3`, в ≥ 7/10
   сидов**. Не «в среднем больше» — именно парное сравнение по сидам.
2. **Цена (как в §10aw):**
   - медиана `ρ_partial` **≤ −0.3** на основной метрике (порог ≥5, `w = spores/cells`, нуль sum/sum);
   - отрицательна в **≥ 7/10** сидов;
   - знак отрицателен **во всех 24 вариантах** метрики.
3. **Стоп-правило (главное).** Если `valid_n` (линий ≥5) снова **< 7/10** — цена в `W2-bud`
   **объявляется неизмеримой по конструкции**, и это записывается как результат:

   > «В мире `W2-bud` цена признака неизмерима: медиана линий 2.5–6.5 при пороге 5, и ни одна из шести
   > конструкций не поднимает её устойчиво выше. Это структурное ограничение мира, а не отсутствие эффекта.»

   Четвёртый рычаг **не ищется**. Шестая переделка — последняя.

## Ожидание (до данных)

На сидах 101–110: `N = 3` — медиана 4.0 линии (`valid_n` 4/10), `N = 1` — 2.5 (1/10). Ожидание для
`one-bud`: медиана **5–7** линий, `valid_n` **5–8/10**, парное преимущество над `N = 3` в 6–9 сидах из 10.
Основание: при `N = 3` предок часто забирает два бутона из трёх; запрет даёт бутоны разным линиям.

## Что будет при разных исходах

| исход | что заявляется |
|---|---|
| `valid_n ≥ 7/10` и цена по критерию | цена **измерима**; вердикт по цене — с оговоркой «на сидах 101–110» |
| `valid_n 5–6/10` | цена **на границе**; публикуется как «направление, вердикт не выносится», рычагов больше нет |
| `valid_n < 5/10` | срабатывает стоп-правило: цена **неизмерима по конструкции** |

## Ограничения

1. Один layout (`uniform`), `freq_dep = 0`, `eps = 4.0`; `N = 3` и `one-bud` — ручные параметры.
2. Три плеча на одних сидах — сравнение парное, но прогоны независимые.
3. Мир `W2-bud` — второй по единице размножения; числа с `W1` и `W2-bud-d2` абсолютно несопоставимы.
