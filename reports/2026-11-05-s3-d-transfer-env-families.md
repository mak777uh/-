# S3 / D — перенос по семействам сред (первый проход), 05.11

**Цель (plan-alive P2/D):** проверить перенос *устойчивого* направленного механизма на другие семейства сред, а не только на другой тайминг/дрейф градиента. Фиксированный лучший устойчивый из B: `gradpos` (направление по row-`gradient_position`, CI после разворота +0.32, оккупация 0.55–0.59 на градиенте) + layout-agnostic локальный `plastic_direction=gradient` (шаг к соседу с макс. ресурсом).

**Метрика (аддитивно, [p0_flip_metric.py](../morphogenesis/scripts/p0_flip_metric.py)):** для `gradient`+flip/drift — прежняя благоприятная половина по текущему `gradient_position` (сопоставимо с P0/P1). Для других раскладок — верхние 50% клеток по *текущему* значению ресурса (`topk` по значению; топ-50% фиксирован по площади). `move_ci`=(up-down)/moves вдоль *текущего* row-`gradient_position` (для row-taxis информативен; для patch-геометрии — диагностический, не целевой). Режим неперерожденный (пропорциональный доход, смертельная цена), 3 сида, 600 шагов, steady-state (без флипа).

## Выводы (осторожно)
1. **`gradpos` (row-gradient, лучший на градиенте) не переносится на patch-геометрию:** он навигирует по глобальной оси `gradient_position`, а пятна ресурсов расположены иначе. На пятнах `gradpos` дал 0.316 (row-CI 0.389) — направление есть, но *не к пятнам*. Это честная граница переноса осевого таксиса, не баг механики.
2. **Layout-agnostic локальный ресурс даёт переносимый небольшой плюс на пятнах** (0.385 > 0.357 random > 0.247 base) и снижает смертность vs baseline, но оккупация ресурсно-богатой половины остаётся умеренной (0.39) — далека от «собрались на богатых патчах». Локальный argmax — слабый сигнал при 4-соседстве/динамике/конкуренции.
3. **`uniform` — почти вырожденный по давлению** в этом режиме (смертей ~0–2 при том же бюджете): «богатая половина» по ресурсу есть по определению метрики, но реальной ценности/отбора мало, поэтому интерпретировать как содержательный перенос нельзя; для переноса нужна **содержательная неоднородность + смена/периодика + смертельное давление**.
4. **Итог P2/D (первый проход):** перенос по *таймингу/дрейфу градиента* подтверждён (B1). Перенос на *семейство геометрий* частичный: row-taxis не переносится; локальный ресурс переносится слабо. Для честного P2 нужны (а) направляющий сигнал, согласованный с геометрией среды (локальный градиент ресурса/патчей), (б) среды со сменой/периодикой/шумом при сохранении R1, (в) метрика «правильной зоны», содержательная для каждой семьи.
