# Протокол «истина или отсрочка»: сводка пяти ответов раунда 2 (28.10)

Это **единый источник правды** для следующей серии. Числа взяты как медиана/наиболее защищённый вариант
из пяти ответов; где модели расходились — записано, какой вариант выбран и почему. Всё, что можно записать
до данных, записано до данных.

## 0. Главное решение: заголовочный показатель

**Заголовочная величина — скорость роста редкой линии при взаимной инвазии.** Эффективное число линий
понижено до **описательной** величины, q-профиль Хилла (q = 0,1,2) — до робастности.

Причина (совпадает у всех пяти): высокое эффективное число может быть следствием (а) медленного исключения,
(б) постоянного притока новых меток, (в) короткоживущих редких линий. Ни одно из этого не доказывает
сосуществование.

## 1. Протокол инвазии (числа фиксированы)

| параметр | значение | обоснование |
|---|---|---|
| поле / ёмкость | 32×32 = 1024 (жёсткая) | как в текущем мире |
| инокулят | **8 клеток** (0.78 %) | медиана ответов (4 / 8 / 8 / 10 / 20); при 1 клетке шум, при ≥64 уже не «редкая» |
| размещение | замена 8 случайных резидентных клеток, энергия/возраст наследуются от заменённых; **рассеянно**, не кластером | исключить энергетический артефакт и пространственное укоренение |
| момент вселения | после прогрева: **шаг 600** (основной), 1200 (проверка «замедленной» фазы) | 600 — фаза после быстрого исключения, но до плато |
| направления | **взаимная инвазия** A→B и B→A | одна перекраска проверяет дрейф, а не механизм |
| горизонт | **1800 шагов** после вселения; продление до 5 демография. поколений, максимум 3600 | короче — примешь рост за сосуществование |
| порог «инвазия состоялась» | **≥160 клеток (15.6 %)** и удержание ≥80 клеток ещё 300 шагов | при 160 нейтральная ложная вероятность ≈ 8/160 = **5 %**; порог 5 % (51 клетка) давал бы 16 % ложных |
| повторы | целевых **128** на плечо, минимум 64 | SE доли при 128 ≈ 4.4 п.п. |
| нуль | **нейтральный клон** (та же демография, тот же вход) + калибровка порога по ≥512 нейтральным реплеям | порог нельзя подбирать после просмотра траекторий |
| родословная | у инвазора **идентификатор основателя**, не зависящий от смены метки | иначе мутанты растворяют инвазор |

**Критерий на уровне прогона:** нижняя граница 95 % ДИ наклона `log(доля/(1−доля))` по событийному времени
> 0 **и** выше 99-го перцентиля нейтрального распределения, **или** достигнут порог 160 с удержанием.

## 2. Событийное время (три оси, одна основная)

Записывать одновременно: (а) **шаги**; (б) **фактические обновления клеток**; (в) **рождения**;
(г) **смерти**. Основная ось для утверждений — **рождения / N** (время по Морану), потому что при
непрерывном почковании «поколение» как дискретный цикл не существует.

Срезы: `s = 300, 600, 1200, 1800, 3600`. **Критерий «это только перемасштабирование времени»:** если кривые
плеча и контроля совпадают в событийном времени в пределах межрепликового 95 % коридора — эффект сведён
к замедлению. Именно это главный риск раунда 1.

## 3. Нормировка и скважность (разделить!)

Текущая схема (глобальные p05–p95 по всему сигналу) **не разделяет амплитуду и скважность** и при 85 %
тишины раздувает шум. Замена:

1. `θ = 0.10` фиксирован, маска `g_t = 1[RMS_t ≥ θ]`, скважность `S = 1 − mean(g_t)`;
2. амплитуда `a_t = clip((RMS_t − θ)/(p95_active − θ), 0, 1)` — процентиль **только по активным**;
3. вход в мир: `p_update(t) = p_base + β_g·g_t + β_a·g_t·a_t` (две ручки вместо одной);
4. калибровка на отдельном фрагменте, **замораживается** до прогонов.

**Контроли (обязательны):** фазовая рандомизация (тот же спектр), IAAFT (спектр + маргинальное
распределение), белый шум с тем же распределением активных амплитуд, перестановка (та же статистика без
времени), та же доля тишины со случайной кластеризацией пауз, постоянная `p`, равная средней.
**Допуск равенства средней:** |Δp̄| ≤ 0.005.

## 4. Такт против рассогласования (три плеча + фазовый контроль)

| плечо | обновления/рождения | трата энергии | смерть |
|---|---|---|---|
| **обычная пауза** | стоп | **продолжается** | **продолжается** |
| **полная заморозка** | стоп | стоп | стоп |
| **контроль без пауз** | то же число событий, без длинных пауз | по модели | по модели |

Плюс плечо «индивидуальные фазовые сдвиги» (та же скважность, та же средняя `p`, но без глобальной
синхронности). **Решающий критерий:** обычная пауза ≠ полная заморозка **в событийном времени** ⇒ пауза
является механизмом; если неразличимы — это перемасштабирование.

## 5. Проверка на оборот меток

Нужны **два** раздельных теста и **учёт по основателям**:

1. учёт родословных: каждой клетке в момент `t₀` присваивается ID основателя, потомки наследуют его;
2. **чоуз без новых меток** с `t₀ = 1800`: минимум 3600 шагов или 10 поколений;
3. **сканы по μ** (0, 0.5, 1, 2 × базового): если разнообразие растёт пропорционально μ — это приток меток.

**Критерий «это был оборот»:** после отключения новых меток старые линии коллапсируют к одной и `q1 → 1.0–1.1`.

## 6. Река (определение, чтобы не называть рекой градиент)

Обязательно: **направленный снос** (среднее смещение ≥ 1 клетки за поколение), **сток/выход** на границе,
**локальная конкуренция** (не только глобальная ёмкость), **число Пекле Pe = vL/D ≥ 3**, измеримое время
пребывания (≥20 % меченых частиц достигают стока за 5 поколений).
Опционально и только отдельными плечами: убежища, локальные ёмкости, миграция против течения.

**Если адвекции нет — термин «градиент притока», не «река».**

## 7. Порядок работ (финальный, согласован)

| # | работа | условие перехода |
|---|---|---|
| 1 | счётчики событий (обновления, рождения, смерти) + **ID основателя** | логи пишутся, старый контроль пересчитан |
| 2 | **K1** реплей расписания + три плеча пауз | воспроизводимость подтверждена |
| 3 | **K2** взаимная инвазия + нейтральная калибровка порога (512 реплеев) | известна базовая вероятность установления |
| 4 | **K3** суррогаты через один замороженный конвейер | тривиальные объяснения исключены |
| 5 | чоуз без новых меток + скан по μ | оборот меток отделён |
| 6 | матрица взаимных инвазий после отключения меток | «сосуществование» защищаемо |
| 7 | модель реки (адвекция + сток + Pe) | только если пункты 1–6 не объясняют эффект |

**Правило формулировок:** до пункта 6 запрещено слово «сосуществование». Допустимо: «число линий на срезе
такого-то событийного времени» и «инвазионный рост редкой линии выше нейтрального».
