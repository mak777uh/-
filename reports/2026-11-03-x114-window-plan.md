# X114 — is the generation-rate advantage an artefact of the horizon? An equal-window test

**Why.** X113 and X113c measured lineage depth and generation rate over the **whole run**: a line that starts late has less time to go deep, and a
long-lived structure has more time than a short-lived one. The rate normalised by lifetime helped, but the *observation window* was still the run's
horizon, so lines still alive at step 6 000 are favoured by construction. This is the exact caveat the claims carry, and it can be tested without
new runs.

**The test.** Give every sister pair the **same time budget**: measure each branch's depth only within a window of fixed length `W = 3 000 steps`
starting at the branch's own birth, and divide by `W`. Both branches then have identical windows, and truncation no longer differs between them.

## 1. Manipulation is connected

X108's twenty runs (seeds 301–310). For each sister pair (two daughters of one mother), compute for each sister the number of **generations reached
within `W = 3 000` steps of her own first appearance** — counting only descendants whose first appearance is inside the window — and the rate
`depth_W / W × 1 000`. Connectedness: at least **300 usable sister pairs** per cell whose both branches have at least one descendant inside their
window; the count is reported.

## 2. Positive control fires (numeric)

Two controls, both required:

1. **Heredity** `≥ 0.35` in both cells on the same pairs (0.548 / 0.480).
2. **The window bites:** the mean depth inside a 3 000-step window must be **lower** than the whole-run depth (X113: 1.479 / 2.213 generations of
   contrast, median depth 3), i.e. the truncation is doing something and the test is not the previous measurement in disguise. The control fires if
   the windowed median depth is strictly below the whole-run median.

## 3. Readout exists and varies

Per cell: the paired sister contrast in `depth_W` and in `rate_W` (generations per 1 000 windowed steps) with bootstrap 95 % intervals, and the
fraction of pairs whose window ends before the run does (the ones for which the equal-window test is exact rather than nominal). Variation exists:
depths inside the window take 0–3 values and rates span an order of magnitude.

## 4. Sensitivity arithmetic

~300–1 200 pairs per cell; the paired difference in `rate_W` has SE ≈ 0.15 generations per 1 000 steps, so the declared resolution is **0.30** — twice
X113c's, because the window throws away half the observation. An effect below that is "unresolved", not absent.

## 5. Refusal rule (fixed before the run)

**Void** if a cell has fewer than 300 usable pairs, heredity below 0.35, or if the windowed median depth is not strictly below the whole-run median.

**The advantage survives the equal window** if the paired `rate_W` contrast is positive with the bootstrap interval excluding zero in both cells.
**The advantage was horizon** if the interval contains zero in both cells while X113c's whole-run rate contrast excluded it.
**Mixed** otherwise, cells reported separately.
