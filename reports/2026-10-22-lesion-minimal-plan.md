# Минимальный носитель и дисперсия при фиксированной геометрии: пре-регистрация

- **ID:** `E02b_lesion_minimal` (пункт очереди — эта же гипотеза, `H-CH-9` + `H-AB-7`)
- **Дата:** 2026-10-22
- **Статус:** пре-регистрация. Прогона нет: GPU-лейн занят волной `E02c_seeddec_*`
  (владелец — `analyst`). Запуск — сразу после освобождения лейна, одним прогоном.
- **Предшественники:** [clusters-3](2026-10-22-clusters3-results.md) — там
  H-CH-8 подтвердила, что **любая половина** скрытых каналов достаточна, а H-AB-6
  показала, что величина асимметрии при идентичной геометрии скачет на 0.125.
- **Гипотезы в реестре:** `lab/registry.json` → `H-CH-9`, `H-AB-7`.

## Зачем эти две проверки вместе

Обе — про «сколько нужно» и «насколько стабильно» в одной и той же модели
(`WP4_R-9_s2000_seed42`, прототип `proto_seed = 35`, 2000 шагов):

1. **H-CH-9** спрашивает, можно ли сузить носитель с половины (6–7 каналов) до
   1–3 каналов. Это прямое продолжение H-CH-8: если избыточность полная, то
   минимальный набор должен быть маленьким; если нет — мы найдём границу.
2. **H-AB-7** спрашивает, является ли разброс 0.125 при одинаковой геометрии
   свойством шума, а не сигнала. Без этого ответа любые «кривые по q» строить
   нельзя (что и записано в §4.11 рукописи).

Обе дешёвые (~25 мин GPU) и не требуют ни обучения, ни новых чекпоинтов.

## H-CH-9 — минимальное достаточное число скрытых каналов

**Формулировка (из реестра).** Минимальное достаточное число скрытых каналов
меньше половины: 1–3 канала при `visible = 0` и открытом гейте живости
восстанавливают тело.

**Дизайн.** Условие одинаково для всех наборов: `visible = 0`, `alive = +8`
(константа `ALIVE_OPEN = 8.0`, как в clusters-3), все каналы вне набора
обнулены. Прототип — `struct_2` (R-9 seed42, `proto_seed = 35`); 12 независимых
шумовых сидов на условие (`p_seed`), 2000 шагов, `every = 50`.

Наборы (16 условий, зафиксированы до прогона, без перебора):

| Размер | Наборы |
| --- | --- |
| 1 канал | `{2}`, `{4}`, `{6}`, `{8}`, `{10}`, `{12}`, `{14}` |
| 2 канала | `{2,3}`, `{5,6}`, `{8,9}`, `{11,12}`, `{13,14}` |
| 3 канала | `{2,3,4}`, `{6,7,8}`, `{10,11,12}`, `{12,13,14}` |

Выбор такой: один канал из каждой половины (2–7 и 8–14) по нечётной позиции,
пары — соседние, тройки — из начала, середины и конца списка. Наборы не
подбирались по прошлым IoU: иначе это был бы перебор, а не проверка.

**Контроли.**

- `none` (без обнуления) — 12/12 тело, иначе прогон недействителен;
- `untrained_current_arch` с тем же набором из 3 каналов (`{6,7,8}`):
  ожидание — 0/12 тела; если untrained даёт тело, метрика тела не различает
  обученное и необученное, и вердикт H-CH-9 откладывается.

**Метрики.** `body_returned` = `body_iou` с прототипом ≥ 0.5 (точное определение
из clusters-3: `row["body_returned"] = body_iou >= IOU_MIN`); `alive`
(`alive_fraction ≥ 0.05`) считается и печатается отдельно; критерий строится на
`body_returned`, чтобы числа были сравнимы с 0.864 / 0.784 / 0.805 из H-CH-8.
`class` замороженной проекцией — описательно, не критерий.

**Критерий (записан до прогона).**

- **подтверждено**, если хотя бы один набор размера ≤ 3 даёт тело в ≥ 11/12 и
  `untrained` в контрольном наборе даёт ≤ 1/12;
- **опровергнуто**, если ни один набор размера ≤ 3 не даёт ≥ 11/12;
- **неоднозначно**, если условие выполнено, но untrained тоже даёт тело
  (шумная метрика) — тогда вердикт не ставится, а отчёт фиксирует поломку
  метрики.

Отдельно фиксируется «порог»: минимальный размер набора, при котором условие
выполнено, — это и есть ответ на вопрос, даже если он равен 3.

## H-AB-7 — дисперсия при фиксированной геометрии

**Формулировка (из реестра).** При фиксированной геометрии среза разброс разности
по сидам мал: `std(d) ≤ 0.05`.

**Дизайн.** Та же модель и прототип. Две геометрии, каждая — 12 независимых
шумовых сидов (`p_seed`), 2000 шагов:

- `c = (40, 24)`: левый срез — обнулить столбцы `[:40]`, правый — `[24:]`;
- `c = (38, 26)`: левый срез — `[:38]`, правый — `[26:]`.

`d = IoU(binary, proto) после левого среза − то же после правого`, на одном и том
же шумовом сиде внутри пары (как в clusters-3: `p_seed = 950000 + idx*10 + side`).
Пары не отбрасываются по массе: геометрия зафиксирована намеренно, и разность
масс входит в `d` как систематическая часть — измеряется именно **разброс**.

**Критерий (записан до прогона).**

- `std(d) ≤ 0.05` в обеих геометриях → величина объясняется геометрией;
- `std(d) > 0.10` хотя бы в одной → шум, кривые по q строить нельзя;
- между — неоднозначно, публикуется как есть (без округления в удобную сторону).

Дополнительно считается `mean(d)` и доля отрицательных `d` (знак — отдельная,
уже установленная часть: 35/35 пар отрицательны).

## Границы

1. Один прототип (`struct_2`, `proto_seed = 35`), один горизонт 2000, одно железо.
2. `struct_1` не тестируется: у него pattern-метрика несамовоспроизводима
   (контроль `none` 0/12), и его числа остаются описательными.
3. Наборы каналов зафиксированы списком выше; подбор «лучшего» набора после
   прогона запрещён.
4. H-CH-9 не доказывает **необходимость** найденного набора — только
   достаточность; обратное утверждение потребовало бы отдельного дизайна.
5. Никаких формулировок о жизни/сознании/интеллекте (AGENTS §3); результат —
   наблюдаемый класс поведения и его границы.

## Бюджет

192 + 48 = 240 развёрток по 2000 шагов ≈ 25 мин на RTX 3070 при 6 с/развёртка
(оценка по переписи E02b: 832 развёртки за 5070 с). Диск: артефакты < 2 МБ,
весов не создаётся. Порог `state.disk.free_gb ≥ 10` проверяется перед запуском.

## Как читать результат

- Если H-CH-9 подтверждена при 3 каналах — «носитель сужается до трёх каналов из
  четырнадцати», и это усиливает §5.5 («форма распределена») без новой
  тренировки.
- Если H-CH-9 опровергнута — «половина — это предел избыточности, меньшие
  наборы не восстанавливают тело», и §5.5 получает нижнюю границу.
- Если H-AB-7 даёт `std > 0.10` — кривые по q закрываются как метод; ссылка в
  §4.11 и §5.5 усиливается. Если `std ≤ 0.05` — значит разброс был свойством
  пар с разной геометрией, и его надо искать в другом месте.
