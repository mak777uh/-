# X138 — does the mixing length scale with the structure or with the wavelength?

**Why.** X136 put the crossover at **16 ± 1 cells** for structures of 29 cells of area (radius 3), where the pattern wavelength is 12 cells. Two explanations fit that number and give different
predictions for a bigger structure:

- if the mixing length is set by the **pattern** (one and a third wavelengths), a doubled structure should still merge up to about 16 cells;
- if it is set by the **structure's own size**, a doubled structure should merge up to about 32.

This is a clean discriminating test with one new lever: the seeding radius. A radius-6 disc is 113 cells of area and — checked before registering — starts as **one** component at
`F = 0.030` and stays one through the first fifty steps, so the manipulation changes the size of the object and not its kind.

## 1. Manipulation is connected

Same probe (`--init-spots R:SEP`, seed-dependent placement, anchored), same inflow `F = 0.030`, same seeds 601–605, same 6 000 steps and dense logging. Only the radius changes: **R = 6**
instead of 3.

| arm | separation | seeds |
|---|---|---|
| control | 0 (one disc of radius 6) | 601–603 |
| sweep | **16, 24, 32, 40** | 601–605 |

Twenty-three runs. The separations span both predictions: 16 is the small-structure crossover, 32 its double. The readout is X136's: one seeded subtree disappearing into the other's
reach, and both subtrees present at the last step.

## 2. Positive control fires (numeric)

Five controls. **The control fires if** all five hold:

1. **The anchor still matches** (the probe is unchanged): the X134b anchor against the committed projection of `x108_f030_s301.json`, key by key.
2. **The radius-6 disc is one structure**: exactly one component of area ≥ 20 at the first logged step, and still one at step 100, in at least 2 of 3 control runs. If the big seed splits,
   the manipulation changes the object rather than its size and the run is void.
3. **Every two-disc arm starts as two components** at the first logged step.
4. **Every run is alive** under the structural rule.
5. **The sweep spans both outcomes**: a separation with absorption in ≥ 3 of 5 seeds and one with ≤ 2. One outcome only means the four points all sit on the same side and the
   discriminating test was not made — that is a void, not a result.

## 3. Readout exists and varies

Per separation: absorbed count, both-alive count, median and per-seed steps to absorption. The control arm reports whether one big disc survives and how large it is at the end.

## 4. Sensitivity arithmetic

Five seeds per point, three-of-five resolution, four separations at 8-cell spacing. The two predictions differ by **16 cells**, twice the spacing, so the design can separate them
without a finer sweep: if 16 cells merges and 32 does not, the pattern sets the length; if 32 merges and 40 does not, the structure does; if both 16 and 32 merge but 40 does not, the
length is between one and three wavelengths and scales with neither simple rule.

## 5. Refusal rule (fixed before the run)

**Void** if the anchor moves, or the radius-6 control is not one structure, or a two-disc arm does not start as two components, or more than one run is dead, or the sweep spans one
outcome.

**The pattern sets it** if 16 merges (≥ 3 of 5) and 32 does not (≤ 2 of 5). **The structure sets it** if 32 merges and 40 does not. **Neither simple rule** if both 16 and 32 merge; the
length is then reported as an interval with the doubling ratio printed, and the report says plainly that the simple scaling hypotheses both fail.
