# H-ALIVE-50 / `R1`: единица размножения в мире без тела — пре-регистрация (только дизайн)

- **Дата:** 2026-10-26
- **Статус:** **план, прогоны не запускаются** до просмотра ведущим. Новый мир ⇒ отдельное решение.
- **Зачем:** всё, что мы измерили, — миры с телом (сетка, колония, компонента). В статье это записано
  как ограничение: «единица размножения решает» проверено в телах. Вопрос: **переносится ли это на
  репликаторы без тела?**

## Что должно быть в мире `R1` (конструкция, а не числа)

**Мир без сетки.** Никакой геометрии, никаких компонент: есть **единицы** (units) и общий пул ресурса.
Это ключевое отличие: в `W1`/`W2-bud` единица размножения была *следствием* геометрии (компонента,
клетка, пара соседей), а здесь она задаётся **прямо** как параметр `k` — сколько репликаторов входят в
одну единицу.

| понятие | как определено в `R1` |
|---|---|
| **единица** | группа из `k` репликаторов, которые размножаются **вместе**: делятся, только если суммарная энергия группы ≥ порога; потомок наследует средний признак группы |
| **линия** | метка основателя единицы; все потомки наследуют метку (с мутацией признака, но **без** смены метки) |
| **приспособленность** | число потомков линии за прогон, нормированное на ожидаемое |
| **возможность отбора** | `I = Var(w)/mean(w)²` по линиям, `w` = потомков на репликатор-шаг |
| **нуль-модель** | условный Пуассон: `X_i ~ Poisson(rate · exposure_i)`, `rate = Σпотомков / Σexposure` (тот же `library/tools/i_null.py`, что в `W2-bud`) |

**Три плеча по `k`:** `k = 1` (репликатор размножается сам), `k = 2` (пара), `k = 8` (группа).
Это **прямой перенос** дизайна §10az/§10ba: та же ось «размер единицы», но без тела.

## Чем эта постановка отличается от `W2-bud` по конструкции (не по числам)

| | `W2-bud` | **`R1`** |
|---|---|---|
| где живёт единица | следствие геометрии (клетка/пара/компонента на сетке) | **явный параметр `k`**, геометрии нет |
| что ограничивает размножение | масса компоненты, свободные соседи, слияние | только энергия группы и пул ресурса |
| откуда берётся «родство» | метка клетки на сетке | метка основателя единицы |
| что может пойти не так | обрезка пятна, слияние, переписывание типа | конкуренция за пул, вымирание без геометрии |

**Предсказание (до данных):** если механизм «единица размножения решает» не зависит от тела, то в `R1`
порядок будет тот же: `k = 1` даёт `I_obs > I_null` в ≥ 7/10, `k = 2` и `k = 8` — нет (не более 1/10).
**Если порядок сохранится** — утверждение переносится за пределы тел. **Если нет** — «единица решает» —
свойство миров с телом, и это надо писать прямо.

## Критерий (до данных)

1. **`k = 1`:** `I_obs > I_null(95 %)` в **≥ 7/10** сидов.
2. **`k = 2`:** не более **1/10**; **`k = 8`:** не более **1/10**.
3. **Монотонность:** медиана `I_ratio` при `k = 1` выше, чем при `k = 2` и `k = 8`, в **≥ 7/10** сидов
   (парное сравнение по сидам).
4. **Не вырождено:** линии с данными ≥ 4 в медиане при `k = 1`; если меньше — серия `invalid_by_data`,
   вердикт не выносится (правило §3c п. 4: знаменатель — часть определения).
5. **Знаменатели:** везде писать `valid_n` и число прогонов, где `I` вычислима; при `valid_n = 0` —
   «**не оценивается**», а не «отбора нет».

## Арифметика до критерия (по §3c)

- энергия единицы: `E_unit = Σ E_i`; порог деления `E*`; после деления `E_unit` делится между родителем
  и потомком **пополам** (иначе размер единицы сам по себе даёт преимущество — конфаундер, который надо
  исключить конструкцией);
- **проверка чувствительности:** доля единиц с `E ≥ E*` в стационарном режиме должна быть **0.2–0.6**
  (не «все» и не «никто»), иначе опыт нечувствителен по конструкции;
- ожидаемая потеря энергии на деление: `c_split`; точка безубыточности: `E* > c_split/(прирост)`.

## Стоимость и порядок

- Реализация: новый модуль `morphogenesis/world/replicator.py` (без сетки), **`world/` не трогается**;
- якоря: `W1`/`W2-bud` не затрагиваются (новый модуль), проверка — `colony/N=1` бит-в-бит остаётся;
- пилот: 3 плеча × 1 сид (3 прогона, минуты); серия: 3 плеча × 10 сидов (30 прогонов ≈ 15 мин,
  репликаторы дешевле пруда).

## Ограничения

1. `R1` — **другая модель**, а не другой мир той же физики: сравнение с `W2-bud` только по порядку, не по
   величинам.
2. `k` задаётся вручную (1/2/8); сетки нет.
3. Без геометрии исчезают все механизмы, которые мы изучали (слияние, обрезка, соседство) — это и есть
   смысл: проверить, держится ли утверждение **без** них.
