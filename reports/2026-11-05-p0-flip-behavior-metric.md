# P0 — метрика поведения при смертельной цене + переворот градиента (05.11)

Пре-регистрация: [`2026-11-05-p0-flip-behavior-metric-plan.md`](2026-11-05-p0-flip-behavior-metric-plan.md).
Артефакты: [`p0_flip_behavior.json`](../morphogenesis/experiments/E09_pond/p0_flip_behavior.json) (ресурсные зоны), [`p0_flip_behavior_v2.json`](../morphogenesis/experiments/E09_pond/p0_flip_behavior_v2.json) (добавлена «правильная» зона = благоприятная половина по градиенту, переворачивается вместе со средой).
Код: [`morphogenesis/scripts/p0_flip_metric.py`](../morphogenesis/scripts/p0_flip_metric.py) (PondRun, gradient + flip_at). Зоны: resource-threshold (rich/poor/mid) + **gradient-half `correct`** (верхняя по `gradient_position` половина в текущий момент; после флипа маппинг инвертируется вместе со средой) — это поведенчески содержательный маппинг «правильной» стороны.

## Конфигурация (неперерожденный режим, R1 пройден)
gradient, `income_mode=proportional`, `income=0.04`, `update_cost=0.038`, `repair_cost=0.022`, `init_resource_fill=1.0`, `resource_regen=0.05`, `seed_cells=32`, `seed_energy=12`, `steps=400`, `flip_at=200`, 3 сида (1–3), grid 32.

## Результат (3 сида, v2, gradient-half `correct`)
- **R1 пройден:** финальные живые (среднее) **515.0**, умерших **2549.3**.
- Доля живых в «правильной» (благоприятной по градиенту, со сдвигом после флипа) половине, средняя по сидам: **до flip 0.682**; **после flip 0.420**. По сидам (before→after): 1: 0.684→0.427; 2: 0.688→0.417; 3: 0.674→0.414 (согласованно у всех).
- Ресурсные пороговые зоны (v1): `rich/(rich+poor)` ~1.99%→0.26% (богатая по порогу почти не занята) — поэтому v1 нечитабелен; v2 использует содержательный маппинг.

## Интерпретация (осторожно)
1. Давление реально (R1). До переворота занятость смещена в благоприятную половину (~68%), но после переворота, когда «правильная» половина меняется местами, доля в новой правильной половине падает до ~42% (< 50%) и **не восстанавливается к дореверсионному уровню** в пределах окна 200 шагов.
2. Это согласуется с **отсутствием адаптивной перестройки** под новый градиент при данном правиле (скорее инерция/распределение, не поведенческая компенсация переворота). «Среда предъявляет цену», но правило **не демонстрирует** восстановление правильной оккупации после сдвига.
3. Формально по духу P0: различие до/после есть, но в сторону **ухудшения** после переворота (не восстановление) — критерий «после переворота выживание в правильной зоне статистически отличается (лучше/адаптируется)» **не выполняется**; корректнее: *без пластичности распределение не перестраивается под переворот*.

## Ограничения
Один неперерожденный режим (подобранный калибровкой), 3 сида, 200 шагов после флипа; метрика — оккупация половин (не траектории). Правило фиксировано (чекпоинт).

## Куда дальше
- Зафиксировать R3-подобный факт для P0 без пластичности: **без P1 (пластичность) правило не восстанавливает оккупацию правильной зоны после переворота**. Следующий шаг по плану — **P1** (внутренний параметр/предсказание, обновление по ошибке) и сравнение восстановления с baseline.
- При необходимости: более длинное окно после флипа / больше сидов для устойчивости оценки.
