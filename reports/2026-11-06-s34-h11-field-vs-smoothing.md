# S34 / H11 — поле-память можно заменить простым сглаживанием ресурса

**Вопрос.** H10 показал, что клетка почти не двигается (0.14 клетки от рождения), значит поле-память
работает как локальный сглаживатель. Прямое следствие: **простое сглаживание ресурса** — без поля, без
памяти, без диффузии — должно делать то же самое.

## Дизайн

Пять плеч при одинаковой подвижности 1:

| плечо | что использует клетка для выбора шага |
|---|---|
| `no_field` | не двигается (контроль) |
| `mem_field` | поле-память (лаг 10, диффузия 0.10, распад 0.05) — лучшее из H6–H10 |
| `smooth_r1` | ресурс, сглаженный по окну 3×3, **без поля** |
| `smooth_r3` | ресурс, сглаженный по окну 7×7 |
| `smooth_r5` | ресурс, сглаженный по окну 11×11 |

Радиусы подобраны так, чтобы охватить эффективную ширину поля: диффузия 0.10 за 10 шагов даёт разброс
порядка √(4·0.10·10) ≈ 2 клетки, то есть окно ~5×5. Сравнение не подстроено ни в чью пользу.

## Результаты (3 сида, 600 шагов, R1 везде 3/3)

| плечо | среднее | по сидам |
|---|---|---|
| `no_field` | 0.260 | 0.254, 0.261, 0.266 |
| `mem_field` | 0.297 | 0.292, 0.283, 0.316 |
| `smooth_r1` | 0.292 | 0.285, 0.294, 0.297 |
| `smooth_r3` | 0.280 | 0.282, 0.265, 0.293 |
| **`smooth_r5`** | **0.299** | 0.300, 0.313, 0.283 |

## Что поняли

1. **Простое сглаживание не хуже поля.** `smooth_r5` даёт **0.299** против 0.297 у поля — разница 0.002,
   шум. `smooth_r1` (0.292) тоже в пределах шума.
2. **Поле как таковое не нужно.** Всё, что даёт поле-память, даёт и сглаживание ресурса по окну. Это
   важное упрощение: сложный механизм (диффузия + распад + история) заменяется одной операцией.
3. **Ширина окна важнее всего остального.** r1 = 0.292, r3 = 0.280, r5 = 0.299 — немонотонно, то есть
   оптимум по ширине есть, но он не резкий. Поле (0.297) попадает в тот же диапазон.
4. **Это честное понижение статуса результата линии H.** Я начинал с идеи «непрерывное поле даёт клетке
   новую информацию». Итог: поле не даёт ничего, чего не даёт сглаживание. Работает не «поле», а
   **размытие сигнала**.

## Что это значит для предложения владельца

Идея с непрерывным полем проверена в четырёх вариантах:

| вариант | результат |
|---|---|
| поле от живых клеток | бесполезно (дублирует локальную информацию) |
| внешний ритм (волна) | бесполезно (не связано с едой) |
| поле-память | работает (+0.038…+0.045) |
| **поле-память против сглаживания** | **сглаживание не хуже** |

То есть **эффект есть, но он не про поле**. Он про то, что клетке полезно смотреть не на одну клетку, а
на окрестность. Это скромнее, но зато проверено и понято.
