# X113 — does size buy generations? A consequence measured in a currency that is not size

**Why.** The line's central open question, written at the end of X97b: size is a **lineage property** here — inherited, generation-spanning,
not branch arithmetic — but nothing yet shows that inheriting it *buys* anything. Every previous attempt at "consequence" used lifetime
(X92, X93), and lifetime is entangled with size: the maze reverses the relation and the effect sits at the noise floor.

This asks the question in a different currency: **lineage depth**. How many generations does a line propagate? That is not a size, not a
lifetime, and not a count of daughters at one moment — it is the one thing a lineage can do that a single structure cannot.

## 1. Manipulation is connected

X108's twenty runs (seeds 301–310, two inflows, dense logging with `--split-new-uid`). From `uid_pairs` build the child map, then per uid:
`depth` = the length of the longest descendant chain below it (0 for a leaf), `subtree` = the number of descendants, and `life` from the
component log.

Connectedness: at least **300 uids** per cell with `depth ≥ 1` (a uid with no descendants has nothing to propagate and is excluded from the
correlations, which is stated in the denominator).

## 2. Positive control fires (numeric)

Two controls, both required:

1. **Heredity on the same pairs:** `ρ(mother area, daughter area) ≥ 0.35` in both cells (0.548 / 0.480 on these worlds) — the control fires
   if both hold.
2. **Depth is not lifetime by another name:** `ρ(depth, life) < 0.8`. If the two were interchangeable, the whole exercise would restate X92;
   the observed value is printed and a correlation above 0.8 voids the series as a re-labelling.

## 3. Readout exists and varies

Per cell: `ρ(area, depth)`, the same partialled on `life`, `ρ(subtree, depth)`, and the **sister contrast** — for every sister pair, the
difference in `depth` between the larger and the smaller sister, paired, with a bootstrap 95 % interval. Variation exists by construction:
depth ranges from 0 to several generations and the lattice and maze differ in branching (X97: 282 and 186 sister pairs with granddaughters).

## 4. Sensitivity arithmetic

300–3 000 uids, so SE 0.018–0.057 for a coefficient; the sister contrast uses 186–282 pairs, SE ≈ 0.06 generations, and the declared
resolution is a **0.10** difference in depth with a bootstrap interval excluding zero. A coefficient below 0.10 is called "no consequence at
this resolution".

## 5. Refusal rule (fixed before the run)

**Void** if a cell has fewer than 300 uids with descendants, if heredity misses 0.35, or if `ρ(depth, life) ≥ 0.8`.

**Size buys generations** if the sister contrast is positive with the interval excluding zero **and** `ρ(area, depth | life) ≥ 0.10` in both
cells.
**No consequence in this currency** if the interval contains zero **or** the partial is ≤ 0.05 in both cells.
**Mixed** otherwise — and then the two currencies (lattice and maze) are reported separately, because X93's reversal says they can disagree.
