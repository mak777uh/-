- **Основание:** §10ae — инвазия не удерживается ни при 1–20 клетках, ни при отдельной
  компоненте, ни при стохастическом слиянии; и там же: **правило не консервативно** —
  из мёртвого состояния зажигает всё поле (1024/1024 на шаге 1), поэтому вопрос
  «основывает ли колонию N клеток» без гейта не задаётся.
- **Инструмент:** `--ignition-gate` (правило не может зажечь клетку без живого
  4-соседа) + `--start-cells 0` + `--invade-on-empty`. С гейтом пустое поле остаётся
  пустым, а посаженный пропагул растёт только сам.

## Вопрос

Среда W1 вообще **поддерживает основание колонии** из N клеток на пустом поле?
Это вопрос не про конкуренцию и не про слияние, а про минимальный живой пропагул: если
20 клеток не основывают колонию, то все наши «инвазии» измеряли порог основания, а не
экологию.

## Дизайн

Пустое поле (`--start-cells 0`), `--ignition-gate`, 32×32, 300 шагов, обученное правило
`checkpoints/world_base_rule.pt`, доход 0.2, цена обновления 0.02, ремонт 0.02,
почкование при массе 24, `layout uniform`, старт заполнен на 0.9, `w-rich` 0.1,
`freq_dep` 1.0, тип на компоненте.

На шаге 1 в самую далёкую от центра свободную точку ставится связное пятно из **N**
клеток (`--invade-at 1 --invade-min-cells 0 --invader-cells N --invade-placement gap
--invade-on-empty`). Резидента нет: это не инвазия, а основание.

**Сетка:** N ∈ {1, 2, 5, 10, 20} × 10 сидов = **50 прогонов** ≈ 75 мин.

**Серия идёт в МОДИФИЦИРОВАННОМ мире.** Гейт зажигания — наша правка (флаг
`--ignition-gate`, по умолчанию **выключен**, поэтому все прежние серии остаются
бит-в-бит). Значит результаты этой серии относятся к миру **с гейтом**, а не к тому, в
котором сделаны D и V8; сравнивать их числа напрямую нельзя, и в §10af это будет
сказано явно.

**Контроль гейта — без новых прогонов.** Зажигание без гейта уже измерено диагностикой
`diag_ignition_{base,nofill,noincome,gate}.json` (4 прогона, по одному сиду, 300 шагов):
1024 живых и `grown_cells` 1023 на шаге 1 при любом ресурсе и доходе, `alive_final` = 0;
с гейтом — 0. Ограничение: контроль n = 1 на условие, не seed-matched с сеткой; поэтому
он используется как качественный (зажигание есть/нет), а не как плечо с долями.

## Метрики (все из артефакта)

- `alive_final` — живых на последнем шаге;
- `max_alive` — максимум живых за прогон;
- `alive_step1` — живых сразу после подсадки (ровно N, если гейт сработал);
- **`grew` = `alive_final > N` И `alive_final > alive_step1`** (оба условия: пятно не
  только выжило, но и превысило собственный стартовый размер — при гейте пропагул сам не
  разрастается, поэтому рост означает именно превышение N);
- `pop_time` — площадь жизни (контроль деградации);
- `final_alive_map` — карта финального живого (для формы колонии, §10x.1).

## Критерий (записать до прогона)

- **Среда поддерживает основание:** выживание при N = 20 **≥ 8/10** и `grew` **≥ 8/10**
  (пятно не просто выжило, а дало потомков), при N = 1 — **≤ 2/10**. Тогда порог
  основания лежит между 1 и 20, и инвазионные серии читаются как «редкая линия ниже
  порога».
- **Среда не поддерживает основание из ≤ 20 клеток:** выживание при N = 20 **≤ 4/10**
  (интервалы с N = 1 перекрываются). Тогда все «инвазии» D/V8 измеряли порог основания,
  и это надо писать прямо; следующий шаг — N = 50/100 (новая сетка, новое решение).
- **Порог ровно на N:** выживание монотонно растёт с N, но не достигает 8/10 при 20 —
  заявляем «порог выше 20», а не «нет основания».
- **Невалидно:** гейт не сработал (на шаге 1 живых > N + 4, то есть поле зажглось) —
  прогон помечается и не входит в доли; `alive_final` = 0 при `max_alive` > N — колония
  выросла и погибла, это отдельная строка (не «не основалась»).

**Статистика:** доли с интервалом Wilson (n = 10); при n = 10 медианы — с диапазоном по
сидам; тренд по N — ранговый, без попарных тестов.

## Ожидание (до данных)

1. При N = 1–2 выживание 0–2/10: одна-две клетки на пустом поле с гейтом не растут
   (в §10ab одна клетка гибла и в богатой колонии). `alive_step1` должен быть ровно N —
   это проверка, что гейт не дал полю зажечься.
2. При N = 20 выживание выше, чем при N = 1, но, вероятно, ниже 8/10: пятно растёт
   медленно, а цена обновления и ремонта съедает запас.
3. Без гейта (контроль) — зажигание 1024 клеток и гибель: это уже измерено
   (`diag_ignition_base.json`), контроль нужен для той же сетки сидов.
4. `pop_time` при N = 20 должен быть выше, чем при N = 1, если пятно вообще даёт рост.

## Ограничения

1. Один layout (`uniform`), 300 шагов, одно правило; перенос на другие среды не
   заявляется.
2. Гейт — наша реализация «правило не зажигает без соседа»; альтернативы (гейт по
   ресурсу, гейт по мембране) не проверяются.
3. Тип на компоненте и `freq_dep` 1.0 — как в D/V8; вопрос о типе здесь не ставится.
4. Ноль клеток в старте — не «мир без жизни»: это старт конкретного прогона.
