# H-CH-12: достаточно ли любой пары каналов внутри носителя. Пре-регистрация

- **Дата:** 2026-10-22
- **Статус:** пре-регистрация. Прогона нет: GPU-лейн занят
  `E02c_R-9_s4000_seed42` (владелец — `analyst`).
- **Основание:** [H-CH-9](2026-10-22-lesion-minimal-results.md) проверила пять пар
  ({2,3}, {5,6}, {8,9}, {11,12}, {13,14}) из двадцати восьми возможных внутри
  информативного набора `{2,3,4,10,11,12,13,14}`. Три из них дали 12/12,
  `{5,6}` и `{8,9}` лежат вне информативного набора.
- **Гипотеза в реестре:** `H-CH-12`.

## Вопрос

Внутри информативного набора достаточна **любая пара** или только три
проверенные? Если любая — избыточность внутри набора полная на уровне пар
(сильнейшее утверждение серии). Если нет — есть пары, которые тело не
собирают, и структура тоньше, чем «информативные против инертных».

## Дизайн

- Условие: `visible = 0`, `alive = +8`, оставлены только два канала пары,
  остальные скрытые обнулены.
- Все 28 пар из `{2,3,4,10,11,12,13,14}` по 12 шумовых сидов: 336 развёрток.
  Три пары, уже измеренные в H-CH-9 ({2,3}, {11,12}, {13,14}), идут как
  **контроли согласованности** — если они не воспроизведут 12/12, прогон
  недействителен.
- Прототип `struct_2` (`proto_seed 35`), 2000 шагов.

## Критерий (записан до прогона)

- **H-CH-12 подтверждена**, если **все 28** пар дают тело ≥ 11/12 при
  воспроизведении трёх контролей (12/12).
- **H-CH-12 опровергнута**, если хотя бы одна пара даёт тело ≤ 10/12.
- **Недействительно**, если любой из трёх контролей даёт < 12/12 — тогда
  сначала разбираемся с прогоном, а не с гипотезой.

## Ограничения

1. Один прототип, один горизонт, одно железо; `struct_1` не тестируется.
2. Пары — минимальный набор из двух каналов; наборы из 3+ уже проверялись
   (H-CH-9: тройки 12/12, H-CH-11: 7 из 8 достаточны).
3. `body` — IoU ≥ 0.5 с прототипом (порог протокола).
4. Если провалятся 1–3 пары, это будет результатом: «не любая пара», с перечнем
   слабых пар; менять порог 11/12 после прогона нельзя.
5. Никаких формулировок о жизни/сознании/интеллекте.
