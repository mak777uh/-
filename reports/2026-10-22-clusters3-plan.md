## H-CH-8 — какая группа скрытых каналов достаточна

В carriers-2 при `visible = 0`, открытом гейте (`alive = +8`) и **целых** скрытых
каналах тело `struct_2` вернулось 12/12 (IoU 0.809). Теперь из скрытых каналов
остаётся только одна группа.

| Условие | Что делаем |
| --- | --- |
| `none` | прототип не тронут (контроль самовоспроизводимости) |
| `group_a_only` | `visible = 0`, `alive = +8`, каналы **8…14 обнулены**, 2…7 целы |
| `group_b_only` | `visible = 0`, `alive = +8`, каналы 2…7 обнулены, **8…14 целы** |

12 повторов × 2 модели (`struct_2` seed42 и необученная), 2000 шагов.

- **Критерий:** `body_iou ≥ 0.5` в ≥ 11/12 у `struct_2` хотя бы для одной группы —
  значит форма хранится в этой группе. Если ни одна группа не держит тело —
  одной группы недостаточно, нужен весь скрытый набор (или их взаимодействие).
- Ворота: контроль `none` обязан держать тело ≥ 11/12, иначе модель исключается.

## H-AB-6 — форма кривой асимметрии

Плотная сетка q = 0.55…0.65 с шагом 0.01 (11 пар) с выровненной массой
(допуск 0.01 доли живых клеток). Предыдущие точки: по q = 0.15–0.49 медиана
росла (ρ = −0.706), а при q = 0.50–0.70 величина падала до −0.14, с максимумом
около −0.63 у q ≈ 0.5–0.63.

- **Предсказание, записанное до прогона:** `max |d|` попадает в **[0.58, 0.68]**
  (то есть горб действительно есть и его высота ≈ −0.63 ± 0.05).
- **Критерий:** предсказание подтверждено, если знак `d` отрицателен во всех
  валидных парах **и** `max |d| ∈ [0.58, 0.68]`. Иначе — не подтверждено.
- Если пара не удаётся выровнять по массе в допуске, она помечается невалидной;
  число валидных пар публикуется.

## Границы

- Один прототип, один горизонт, одно железо; контраст с untrained — одна
  необученная инициализация.
- Группы 2–7 и 8–14 выбраны заранее как равные по размеру; перебор всех разбиений
  не делается.
- Дозу-ответ описывает один прототип `struct_2`, а не все модели.
- Никаких «жизнь/сознание/интеллект»; рамка — наблюдаемый класс поведения
  ([`AGENTS.md`](../AGENTS.md) §3).
