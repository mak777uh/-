# H-ALIVE-53 / Цена признака: критерий на среднем по Фишеру (15 новых сидов) — пре-регистрация

- **Дата:** 2026-10-27
- **Статус:** пре-регистрация **до данных**. Запуск — только после коммита этого файла.
- **Зачем:** цена признака остаётся «знак твёрд, величина не определена». Причина — критерий на
  **медиане** ρ по сидам: медиана неэффективна при малом числе прогонов, и бутстрэп по **существующим**
  8 значениям интервал не сужает (при n = 30 верхняя граница −0.281). Но добавление **новых** сидов —
  это другое: SD(z) пересчитывается по большему числу прогонов, и верхняя граница уходит ниже −0.3 уже
  при N ≈ 14–15 (проверка библиотекаря, B-087).

## Что именно меняется — и что НЕ меняется

| | было (§10ax) | стало (эта серия) |
|---|---|---|
| мир и конструкция | `W2-bud`, `--one-bud-per-lineage` | **то же самое**, без изменений |
| число прогонов | 10 (сиды 101–110) | **+15 новых** (сиды 201–215), итого 25 |
| оценка центра | медиана ρ по прогонам | **среднее по Фишеру**: центр = `tanh(mean z)`, `z = artanh(ρ)` |
| интервал | бутстрэп медианы | **95 % ДИ по z**: `mean z ± 1.96·SD(z)/√n`, обратно `tanh` |
| критерий | медиана ≤ −0.3 | **центр ≤ −0.3 И верхняя граница 95 % ДИ < −0.3** |

**Порог −0.3 не меняется. Определение ρ не меняется** (стандартный частный Спирмен, гейт
`check_metric_definitions.py`). Меняется **оценка центра и способ интервала**, и это объявлено до данных.

## Знаменатель (часть определения, §3c)

- **`n` = число прогонов с вычислимой ρ** (`valid_n`), а не число запущенных;
- отдельной строкой публикуется, **сколько сидов не дали ρ** и почему (порог «линия с данными = ≥5 клеток
  и спора», гейт манипуляции);
- прогоны без ρ **не** входят в `mean z` и **не** считаются нулями.

## Критерий (до данных)

1. **Центр** = `tanh(mean z)` по прогонам с вычислимой ρ.
2. **Верхняя граница** = `tanh(mean z + 1.96·SD(z)/√n)`.
3. **Вердикт «цена ≥ 0.3»** ставится, только если **центр ≤ −0.3 И верхняя граница < −0.3**.
4. Если центр ≤ −0.3, но верхняя граница ≥ −0.3 — **величина не определена статистикой**, вопрос
   закрывается (см. опровержение).

## Опровержение (до данных)

- **Верхняя граница ≥ −0.3 при N = 15** ⇒ величина **не определяется статистикой**; вопрос закрывается
  окончательно, дальнейшие сиды не набираются (это записывается как результат, а не как неудача).
- **Центр > −0.3** (то есть среднее сместилось к нулю) ⇒ «цена» как количественное утверждение **опровергнута**
  на этой конструкции; знак публикуется отдельно.

## Обязательное допущение

Новые сиды сняты **тем же `git_code_commit`** и **тем же конфигом**, что серия `w2bud_onebud`
(`--one-bud-per-lineage`, 600 шагов, `m = 0.05`, `mutation_trait_sigma = 0.05`, `eps = 4.0`,
`freq_dep = 0`, `spore_bias = score`, `invest_mode = fixed`). Если конфиг или код отличаются — это
**новая серия**, а не расширение, и критерий к ней не применяется.

## Ожидание (до данных, для последующей сверки)

По существующим 8 значениям: медиана −0.478, среднее по Фишеру **−0.603**, SD(z) = 0.642,
ДИ [−0.816, −0.249]. При N = 15 верхняя граница ≈ **−0.357**. Значит при сохранении распределения
критерий **выполнится**; если новые сиды сместят распределение к нулю — нет.

## Дизайн прогонов

15 прогонов, сиды **201–215** (не пересекаются с 101–110), 600 шагов, конструкция `one-bud`, через
`lab.py run` (`owner=scientist`), манифесты всем. ≈ 2.5 мин на прогон ⇒ **~38 минут**.

## Оговорки

1. Расширение выборки **не** меняет мир и не проверяет механизм — это статистика, а не физика.
2. Между-сидовый SD(z) может измениться на новых сидах; тогда ДИ пересчитывается по **объединённым** 23–25
   прогонам, а не по старым 8.
3. Критерий на среднем по Фишеру **чувствителен к выбросам** меньше, чем арифметическое среднее, но
   публикуются обе оценки (медиана, среднее по Фишеру) — чтобы читатель видел, чем именно получен вердикт.
