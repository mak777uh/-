# F-IGNITE-1 (рабочий номер F-17): гейт зажигания — формальная опора серии основания

- **Дата:** 2026-10-25
- **Формализация:** [`formal/Ignition.lean`](../formal/Ignition.lean) — 4 теоремы,
  `lean_check.py` зелёный.
- **Питоновский аналог:** `morphogenesis/tests/test_pond.py::
  test_ignition_gate_invariant_over_run` — на каждом шаге прогона с гейтом проверяется
  `newAlive ⊆ dilate4(alive_prev)`.

## Утверждение

При включённом гейте каждая клетка, ставшая живой на шаге `t+1`, имела живого 4-соседа
на шаге `t`:

```
∀ c ∈ newAlive(s, t+1), ∃ n ∈ N4(c), alive(n, t)
```

Следствие (индукция по `t`): **из пустого поля гейт не зажигает ничего ни на одном
шаге** — пустое поле остаётся пустым. Это и есть то, на чём стоит §10af.

## Что опровергнет

- реализация, где новая живая клетка появляется без живого 4-соседа (тогда `newAlive`
  не вкладывается в `alive ∪ N(alive)`);
- гейт, который гасит уже живые клетки (пустое поле перестало бы быть инвариантом по
  другой причине).

## Теоремы

| теорема | что говорит |
|---|---|
| `new_alive_has_live_neighbour` | основное утверждение: у каждой новой клетки есть живой 4-сосед на предыдущем шаге |
| `empty_stays_empty_step` | пустое поле остаётся пустым после одного шага гейта |
| `empty_stays_empty` | индукция по `t`: из пустого поля не зажигается ничего ни на одном шаге |
| `no_new_from_empty` | если поле пусто, «новых» клеток нет (следствие для счётчиков) |

## Питоновский аналог (обязателен, §6c п.2)

`test_ignition_gate_invariant_over_run`: прогон 12 шагов с `ignition_gate=True`; на
каждом шаге сравниваются маски `alive` до и после, новые клетки обязаны лежать в
4-расширении предыдущей маски. Контроль «без гейта» — измерен отдельно
(`diag_ignition_base.json`, §10ae): из пустого поля правило зажигает 1024 клетки на
шаге 1, `grown_cells` 1023, то есть без гейта инвариант нарушается на первом же шаге.

## Что осталось вне формализации

1. **Обученное правило** — поведение сети (плавающая точка) не формализуется (§6c п.5);
   теорема говорит о шаге мира при произвольной функции `fire`, а не о том, что правило
   предлагает.
2. **Соседство на торе** — в Lean модель на `Nat × Nat` без заворачивания краёв; в коде
   `_gate_ignition` тоже без заворачивания (край считается отсутствующим соседом), это
   совпадает.
3. **Гейт по ресурсу/мембране** — не формализуется, это другие варианты правила.

## Место в рукописи

§4h и §10af опираются на «гейт не даёт зажечь из мёртвого состояния». Теперь это
утверждение проверяется независимо (Lean) и на конкретном прогоне (Python), а не только
тем, что мы написали флаг и посмотрели глазами.
