какие решения нужны от владельца. Он не переписывает отчёты; все числа взяты из
закрытых экспериментов, каждая строка ссылается на источник.

## 2. Пять результатов, которые я считаю главными

1. **`struct_2` — не свойство рецепта.** 0/3 новых тренировочных сидов дали его
   (E02c), повтор своего сида — побитовый и 64/64 (seed42 repro).
2. **Он — свойство бассейна инициализации.** При init=42 класс вернулся с тремя
   разными порядками данных (64/64, 63/64, 60/64), при init=101 — ни разу
   (H-E02C-6 опровергнута в пользу этого чтения).
3. **Он существует только в одной клетке «точность × горизонт».** TF32@2000 —
   `struct_2`; FP32@2000 и @4000 — `struct_1`; TF32@4000 — `death`. Точность
   необходима, но не достаточна.
4. **У формы нет малого ядра, но есть вырожденность.** Каналы `{3}` (12/12,
   IoU 0.839) и `{14}` (12/12, 0.721) достаточны по отдельности; набор из
   восьми необходим как набор, любые семь из него достаточны, шесть без
   обоих «якорей» — тоже 12/12. Но 11 пар из 28 не дают тело, а `{2,14}`
   падает в 0/12 при работающем `{14}`: достаточность немонотонна.
5. **Асимметрия: правая сторона детерминирована, левая — континуум.** `std`
   0.036 против 0.154; два режима опровергнуты, распределение одномодальное
   (0.127–0.722, пик ≈ 0.2). Знак устойчив всегда; величина смысла без
   распределения не имеет, и класс её не видит (IoU 0.127 — всё ещё `struct_2`).

## 3. Что открыто

| Вопрос | Статус | Что нужно |
| --- | --- | --- |
| `H-E02C-8` — бассейн или совпадение трёх клеток | пре-регистрация готова, критерий зафиксирован | **решение владельца**, ~3 ч 50 мин GPU |
| `H-CH-14` — механизм разрушения при добавлении канала | пре-регистрации нет | 12 условий, ~15 мин |
| `H-AB-11` — структура у границы среза | нет протокола | пре-регистрация + 10 мин GPU |
| `H-EX-1` — механизм `death` при 4000 шагах | нет протокола | снимки 2000→4000 |
| `H-REPRO-2` — torch 2.11 | блокировался сетью | сеть + повтор загрузки |

## 6. Чего в проекте нет (и не будет без решения)

- независимого воспроизведения **обучения** на другом стеке: попытка сделана и
  не прошла, механизм частично назван (TF32), остаток (версия/алгоритмы cuDNN)
  не разделён;
- частоты `struct_2` по сидам: для неё нужна волна `H-E02C-8`/`H-E02C-10`;
- утверждений о жизни/сознании/интеллекте: запрещены контрактом (§3) и не
  поддерживаются данными.
