## Аннотация

Две проверки, критерии записаны до прогона. Первая: сколько скрытых каналов
достаточно, чтобы вернуть тело `struct_2` при обнулённой текстуре и открытом
гейте? Ответ оказался резче ожидаемого: **один канал — 14-й** — даёт тело
12/12 (IoU 0.721). Но «любой набор ≤3 достаточен» неверно: `{6,7,8}` даёт 0/12,
`{8,9}` — 0/12, `{5,6}` — 1/12. Носитель не размазан равномерно: информативны
каналы ≈ 2–4 и 10–14, каналы 5–9 инертны. Вторая проверка: объясняется ли
величина асимметрии геометрией среза? Нет: при фиксированной геометрии
`std(d)` = 0.167 и 0.114 — это шум, а не сигнал, при устойчивом знаке (24/24).

## Короткий ответ

| Вопрос | Ответ |
| --- | --- |
| Минимальный достаточный набор | **1 канал** (`{14}`, тело 12/12) |
| Любой набор ≤3 работает? | Нет: `{6,7,8}` 0/12, `{8,9}` 0/12 |
| Где носитель | ≈ 2–4 и 10–14; 5–9 инертны |
| Величина асимметрии от геометрии? | Нет: `std(d)` 0.167 / 0.114 |
| Знак асимметрии | Устойчив: 24/24 пар отрицательны |

## Один канал вместо половины

Прошлая серия закончилась выводом «любая половина скрытых каналов достаточна»
(H-CH-8: 2–7 → 12/12, 8–14 → 12/12). План H-CH-9 спрашивал, можно ли сузить до
одного-трёх каналов, и заранее перечислил 16 наборов, чтобы не выбирать
«лучший» после прогона.

Сузить можно:

| Набор | Тело | IoU |
| --- | ---: | ---: |
| `{14}` | **12/12** | 0.721 |
| `{2,3}` | **12/12** | 0.847 |
| `{11,12}` | **12/12** | 0.818 |
| `{13,14}` | **12/12** | 0.774 |
| `{2,3,4}` | **12/12** | 0.841 |
| `{10,11,12}` | **12/12** | 0.760 |
| `{12,13,14}` | **12/12** | 0.809 |
| `{12}` | 5/12 | 0.472 |
| `{5,6}` | 1/12 | 0.286 |
| `{6,7,8}` | 0/12 | 0.128 |
| `{8,9}` | 0/12 | 0.095 |
| `{2}`, `{4}`, `{6}`, `{8}`, `{10}` | 0/12 | 0.10–0.22 |

Но заодно выяснилось, что избыточность **не равномерная**. Семь каналов из
четырнадцати (5–9) сами по себе тело не собирают, а `{6,7,8}` — ровно середина
диапазона — даёт 0/12, хотя половина 8–14 целиком даёт 12/12. То есть форма
восстановима из *конкретных малых* наборов, а не из любого: «ни один канал не
обязателен» (H-CH-2) и «любой набор заменим» — разные утверждения, и второе
неверно.

Инженерное следствие: если искать «где хранится форма», ответ теперь такой —
в каналах 2–4 и 10–14 хранится информация, достаточная для сборки тела; каналы
5–9 в этой задаче инертны, хотя их удаление не разрушает форму, пока целы
остальные.

## Величина асимметрии — шум даже при фиксированном срезе

План H-AB-7 фиксировал две геометрии среза и по 12 независимых шумовых сидов,
чтобы отделить «величина зависит от геометрии» от «величина — шум».

| Геометрия | mean(d) | `std(d)` | Размах | Отрицательных |
| --- | ---: | ---: | --- | ---: |
| c = (40, 24) | −0.379 | **0.167** | −0.569 … −0.007 | 12/12 |
| c = (38, 26) | −0.472 | **0.114** | −0.626 … −0.253 | 12/12 |

Порог был `std ≤ 0.05` (геометрия) и `> 0.10` (шум). Обе геометрии — шум, причём
вторая в два раза выше порога. Значит разброс величины не объясняется ни долей
удалённого (H-AB-5, H-AB-6), ни геометрией среза.

Практический вывод: разность IoU «лево минус право» — надёжный **детектор**
структурной асимметрии (24/24 отрицательных) и ненадёжная **мера** её величины.
Для меры нужен другой инструмент: усреднение по многим стартам с доверительным
интервалом или геометрическая мера, не зависящая от шума регенерации.

## Оговорки

1. Один прототип (`struct_2`, `proto_seed 35`), один горизонт 2000, одно железо.
2. Наборы каналов зафиксированы до прогона; подбора «лучшего» набора не было.
3. Класс оставался `struct_2` 12/12 во всех условиях — критерий строился на теле
   (IoU ≥ 0.5), а не на классе.
4. Контроли: `none` — 12/12, untrained — 0/12 тела при `alive` 12/12.
5. Никаких выводов о жизни/сознании/интеллекте.
