## Аннотация

Третий шаг серии «где форма». H-CH-10 показала, что набор {2,3,4,10–14}
необходим, а {5–9} недостаточен. Здесь проверялось, есть ли **внутри**
информативного набора канал, без которого тело рушится. Ответ: нет. Все семь
условий «убрать один канал» дают тело **12/12** (IoU 0.808–0.846 при контроле
0.823). Внутри набора — полная взаимозаменяемость по одному каналу; необходимость
существует только на уровне всего набора из восьми.

## Короткий ответ

| Вопрос | Ответ |
| --- | --- |
| Есть канал, без которого тело рушится? | **Нет**: все 7 условий — 12/12 |
| Разброс IoU между условиями | 0.808–0.846 — шум |
| Класс и живость | `struct_2` 12/12, `alive` 12/12 везде |
| Что тогда «необходимо»? | весь набор {2,3,4,10–14} (H-CH-10) |

## Три уровня, которые нельзя путать

| Уровень | Верно | Не верно |
| --- | --- | --- |
| Один канал | `{14}` достаточен | «любой одиночный канал достаточен» |
| Весь набор | `{2,3,4,10–14}` необходим | «достаточно любой половины скрытого состояния» |
| Внутри набора | любой набор из 7 из 8 достаточен | «есть канал-хранилище» |

Это не противоречия, а разные вопросы. «Можно ли собрать тело из этого
подмножества?» и «что будет, если убрать этот канал?» — разные эксперименты, и
на одном прототипе они дают разные ответы: канал 14 **достаточен**, но **не
необходим**; набор из восьми **необходим**, но ни один его член не необходим.

Такая структура — распределённая, но ограниченная: избыточность внутри
информативной части очень высокая (потеря любого одного канала бесплатна, а по
H-CH-9 — и семи из восьми), но за пределами этой части формы нет вовсе
(`{5–9}` → 3/12).

## Почему это полезно методологически

Если бы мы остановились на H-CH-8 («любая половина достаточна»), картина была
бы «форма размазана по скрытому состоянию». Три последовательных уточнения
показали, что это неточно: размазана она по **конкретным восьми каналам**, шесть
из которых по отдельности бесполезны, а один (`{14}`) достаточен сам.

Практическое следствие для абляций: удаление одного канала — почти всегда
«ничего не произошло», и это не значит, что канал не важен. Чтобы увидеть
структуру, нужны либо удаление целых групп (H-CH-10), либо проверка
достаточности малых наборов (H-CH-9). Одиночные абляции отвечают только на
вопрос необходимости.

## Оговорки

1. Один прототип (`struct_2`, `proto_seed 35`), один горизонт 2000, одно железо.
2. Удалялся ровно один канал; комбинации двух и более не перебирались.
3. `body` — IoU ≥ 0.5 с прототипом (порог протокола).
4. `struct_1` не тестировался: у него pattern-метрика несамовоспроизводима.
5. Никаких выводов о жизни/сознании/интеллекте.
