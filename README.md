# 🧠 Morphogenesis: Система Эмерджентного Интеллекта

**Morphogenesis** — это исследовательский фреймворк для моделирования возникновения когнитивных способностей (памяти, обучения, адаптации) в динамических системах на основе клеточных автоматов. Проект объединяет биологически инспирированные алгоритмы с современными подходами к управлению экспериментами и самоанализу системы.

## 📖 Что такое Morphogenesis?

Проект исследует гипотезу о том, что сложные когнитивные функции могут возникать ("эмерджить") из взаимодействия простых элементов по локальным правилам. 

### Ключевые концепции:
1. **NCA (Neural Cellular Automata)** — ядро системы, где каждая "клетка" имеет состояние и обновляется по правилам соседства.
2. **Когнитивный слой** — протоколы для самонаблюдения, анализа стресса и генерации отчетов о состоянии системы.
3. **Менеджер экспериментов** — инструмент для воспроизводимого запуска симуляций с различными параметрами.

## 🛠️ Основные компоненты

### 1. Ядро (NCA Core)
Файл: `cognition/nca_core.py`
- Реализует логику клеточного автомата.
- Управляет состоянием, шумом, границами и правилами обновления.
- Поддерживает различные топологии (плоская, сфера, тор).

### 2. Когнитивный протокол
Файл: `cognition/protocol.py`
- Определяет интерфейсы для самонаблюдения.
- Реализует механизмы обнаружения аномалий и стресса.
- Содержит сценарии экстремальных воздействий.

### 3. Репортер
Файл: `cognition/reporter.py`
- Агрегирует метрики системы.
- Формирует читаемые отчеты для человека и агента.
- Логирует ключевые события жизненного цикла.

### 4. Менеджер экспериментов
Файл: `experiment_manager.py`
- CLI-утилита для запуска симуляций.
- Поддержка конфигурации через аргументы командной строки.
- Логирование результатов в файлы.

## 📋 Инструкция по работе

### Для разработчиков
1. **Запуск тестов**: Регулярно проверяйте изменения через `pytest tests/ -v`. Все 43 теста должны проходить.
2. **Добавление функционала**: 
   - Новые правила NCA добавляйте в `nca_core.py`.
   - Новые когнитивные паттерны — в `protocol.py`.
3. **Линтинг**: Убедитесь, что код не содержит `SyntaxWarning` (особенно в docstrings).

### Для исследователей
1. **Настройка эксперимента**: Используйте `experiment_manager.py` с нужными параметрами (размер сетки, уровень шума, количество шагов).
2. **Анализ результатов**: Отчеты генерируются автоматически через `reporter.py`.
3. **Стресс-тестирование**: Запустите протоколы из `protocol.py` для проверки устойчивости системы.

### Для AI-агентов
- **Входные данные**: Состояние сетки (`grid`), метрики (`metrics`), история событий (`history`).
- **Выходные данные**: Рекомендации по изменению параметров, флаг тревоги (`alert`), структурированный отчет.
- **Интерфейс**: Классы в модуле `cognition` предоставляют методы `observe()`, `analyze()`, `report()`.
