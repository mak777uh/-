# CHANGELOG — manuscript

Журнал вкладов в рукопись. **Правило append-only:** старые записи не
переписываются, не удаляются и не «уточняются на месте». Новое понимание,
исправление числа или смена формулировки оформляются **новой** записью с датой и
причиной; история остаётся видимой в git и здесь.

## Формат записи

```
- **YYYY-MM-DD, vX.Y** — <experiment_id> — §<раздел> — что добавлено.
  Источник: <отчёт/артефакт>.
```

Одна запись = один закрытый кусочек. Если эксперимент ещё не закрыт, запись
помечается `pending` и не содержит чисел.
